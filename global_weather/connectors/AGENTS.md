# Правила коннекторов

Применяются AGENTS.md и протокол 02. Сетевых вызовов при import нет.
Скачивание — явная команда с разрешением оператора, таймаутом и объёмным лимитом.
Не логировать ключи, не следовать произвольным URL и не перезаписывать исходники.
Проверить UTC, QC, физические единицы, накопления, версии и контрольные суммы.
Обязателен тест без сети на синтетическом примере с плохими полями и пропусками.
Отдельно указывать локальное/сетевое испытание, отсутствие декодера и карантин.
