# Правила стенда

Локальная поверхность, один процесс, никакого произвольного исполнения кода.
Не удалять различие synthetic/real; RMSE без целей — null. Никаких CDN и карт API.
Файлы только в управляемом каталоге; сохранять CSRF, Host-проверку и защиту от
перезаписи/ссылок. Запрос не получает доступ к ключам или произвольным путям.
UI показывает причину ошибки, время, единицы и ограничения. Геометрия и профили
рисуются из реального результата задачи, не из декоративной фиктивной выборки.
Перед изменением: API-тесты, процессный запуск, браузерный сценарий и проверка
мобильного переполнения. Протокол исполнения не считать научной верификацией.
