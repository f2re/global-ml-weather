# global-ml-weather

Исследовательская модель глобального прогноза по наблюдениям за 12 часов.

Целевая постановка: сферическая гексагональная сетка с 12 пятиугольниками, восстановление трёхмерного состояния атмосферы на стандартных изобарических уровнях и прогноз до 72 часов. Наземные и аэрологические наблюдения могут быть разреженными; российские спутниковые продукты принимаются только с проверенными единицами, калибровкой и временем доступности.

Репозиторий инициализирован для разработки. Обученных весов и подтверждённого качества прогноза пока нет.
