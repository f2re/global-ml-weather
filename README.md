# global-ml-weather

Глобальная модель «наблюдения → состояние атмосферы → прогноз до 72 часов».
История — 12 часов; наземные станции и радиозонды могут отсутствовать частично.
Спутниковые источники: «Электро-Л», «Арктика-М», «Метеор-М» / МСУ-МР и МТВЗА.

**Статус: исследовательский программный прототип 0.1.0. Обученных весов и
подтверждённого качества прогноза нет. Демонстрационные значения нельзя
использовать как прогноз погоды.**

## Реализовано

- Двойственная икосаэдрическая сетка вокруг всей Земли: гексагоны и 12
  пятиугольников, реальные сферические площади, соседство и несколько масштабов.
  Это собственная сетка, не H3; её индексы с H3 несовместимы.
- Приём нормализованных физических наблюдений через JSONL, учёт времени
  поступления и ревизий, разреженных профилей, источников, каналов и пропусков.
- Кодировщик наблюдений, 12 последовательных GRU-обновлений, вертикальные блоки
  и многомасштабное графовое ядро на PyTorch.
- 37 изобарических уровней 1000–1 гПа; T, q, u, v, геопотенциал и omega.
  У поверхности — T2, Td2, ветер, давление, количество осадков за шаг и облачность.
- Авторегрессионный расчёт до +72 ч. По умолчанию шаг 3 ч, доступны 1 и 6 ч;
  обучение для другого шага требуется отдельно.
- Независимые маски наличия входов, целей обучения, уровней над поверхностью и
  области выдачи. Область выдачи не обрезает глобальную динамику.
- Функция обучающего шага, проверка непересечения временных выборок, тесты,
  синтетический расчёт и проверка обратного распространения ошибки на CPU.

Реальные снимки SatDump/CBOR пока не декодируются. JSONL — контракт после
калибровки, геопривязки и контроля качества, а не замена этих операций.
Микроволновое измерение с пятном больше ячейки отвергается до реализации
антенного оператора. Набор доступных каналов задаётся явным реестром;
30 транспортных каналов нельзя автоматически объявлять 30 физическими.

## Запуск

Python 3.10+, NumPy, SciPy, PyTorch. Docker не нужен.

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
# Для CPU без CUDA:
python -m pip install 'torch>=2.2,<3' --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
python -m pytest -q

# Геометрия: 642 ячейки, без нейросети.
global-weather grid --mesh-level 3 --output outputs/grid

# Необученная сеть, синтетические наблюдения, 25 сроков: 0,3,...,72 ч.
global-weather demo --mesh-level 1 --horizon-hours 72 --output outputs/demo

# Два шага оптимизатора на синтетической задаче; не обучение метеорологии.
global-weather train-smoke --optimizer-steps 2 --output outputs/smoke
```

Команды запускаются и без установки пакета:
`PYTHONPATH=. python -m global_weather.cli demo`.

`grid.npz` содержит сетку и границы ячеек. `synthetic_forecast.npz` — массивы,
единицы, сроки UTC, уровни, маски и отметку синтетического происхождения.
`report.json` фиксирует размеры модели и параметры запуска. Формат NPZ выбран
для проверочного примера, не как окончательное хранилище многолетнего архива.

Маска региона: `--region SOUTH NORTH WEST EAST`; WEST > EAST означает
пересечение линии смены дат. Отбор идёт по центрам ячеек, без расчёта доли
площади на границе региона.

```bash
global-weather validate-observations --observations observations.jsonl \
  --issue-time 2026-10-03T12:00:00Z --output outputs/admission
```

Для спутников добавьте `--variables path/to/variables.json` с физическим
реестром каналов: [контракт данных](docs/DATA_CONTRACT.md).
Режимы demo/train-smoke намеренно не принимают реальные наблюдения: выдача
необученной сети не должна выглядеть оперативным прогнозом.

## Структура

`grid.py` — геометрия; `contracts.py`, `observations.py` — приём данных;
`model.py` — восстановление состояния и динамика; `vertical.py` — вертикальная
координата и диагностические ограничения; `losses.py`, `training.py` — обучение;
`cli.py` — воспроизводимые проверки.
