# Работа с проектом

Проверка: `PYTHONPATH=. python -m pytest -q` и
`PYTHONPATH=. python -m global_weather.cli train-smoke --output outputs/check`.

Не выдавать синтетические данные за наблюдения или рабочие прогнозы. Сохранять
различие времени наблюдения и готовности. Не смешивать маски входов, целей,
подземных уровней и области выдачи. Маска выдачи не меняет глобальную динамику.
Не подставлять реанализ в отсутствующие входы. Не считать raw counts кельвинами.
Спутниковые каналы добавлять через явный реестр с источником и платформой.
Не использовать предсказанное ps для сокрытия ошибки по обучающим целям.
Изменения сетки, нормировок и вертикальной координаты требуют проверки схемы.
Для больших сеток сначала измерять память; CPU-пример не является оценкой
вычислительной стоимости полноценного глобального обучения.

## Дополнения 0.2

Запуск новой ветви: `python -m global_weather.adaptive_cli`.
Нормы — фиксированный NormalizationBundle, не online fit. Не заменять яркостную
температуру нормировкой T воздуха. Не масштабировать 6h статистики на 3h.
Источник кода не равен хэшу облачных файлов; неизвестный fit_period не выдумывать.
Проверять совместимость checkpoint до изменения весов. Сохранять различие между
адаптацией активаций, динамическим сгущением и переобучением: реализовано первое.
HEALPix, полный водный бюджет и реальные обученные веса не объявлять готовыми.
