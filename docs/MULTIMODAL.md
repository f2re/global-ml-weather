# Многомодальная модель и адаптеры

## Статус

Реализованы связанные спутниковые кодировщики и обработка разреженных наблюдений.
Они подключены к действующему циклу подготовки, обучения, оценки и прогноза.
Глобальная сетка, 37 выходных изобар и горизонт 72 часа сохраняются.
Реальных обученных погодных весов пока нет.

## Структура

| Источник | Кодировщик | Ограничение |
|---|---|---|
| «Электро-Л» | Отдельная ResU-Net и ConvGRU | Проверенные каналы на неизменной локальной сетке |
| «Арктика-М» | Отдельная ResU-Net и ConvGRU | Смена геометрии требует предварительного совмещения |
| МСУ-МР | Отдельная ResU-Net и ConvGRU | Реальные интервалы проходов, без размножения по часам |
| МТВЗА | Спектральный MLP, GRU и антенные связи | Физическая калибровка и веса пятна поступают отдельно |
| Станции и аэрология | Совместное кодирование и локальное внимание | Маски, давление, возраст и расстояние сохраняются |
| Производные продукты | Скалярный кодировщик с методом и возрастом | Продукт не заменяет исходное наблюдение |

ResU-Net содержит четыре масштаба и три связи пропуска.
При базовой ширине 16 используются 16, 32, 64 и 128 признаков.
Остаточный блок содержит две свёртки 3×3, GroupNorm и GELU.
Выходные признаки возвращаются на исходную локальную сетку изображения.

ConvGRU получает фактические интервалы и возраст кадров.
Отсутствующий пиксель не обновляет состояние.
Пропуски и ночные отражательные каналы исключаются отдельными масками.
Нормы воздуха не используются для яркостной температуры.

Разреженное внимание работает отдельно по источникам и вертикальным позициям.
Для каждого запроса используются ограниченные радиус и число соседей.
Число голов равно четырём.
Местоположение радиозонда задаётся доступными координатами и давлением, а не вымышленным полным профилем.

```text
Физические последовательности → ResU-Net / спектральный MLP → ConvGRU / GRU
Разреженные сообщения → локальное внимание
Производные продукты → отдельные нормированные признаки
                       ↓
          Перенос признаков на сферическую сетку
                       ↓
             Внимание между источниками
                       ↓
         Сжатое состояние и адаптивный граф
                       ↓
        Профили и поверхность: 0, 3, …, 72 часа
```

Поле рельефа поступает в начальное состояние и физические признаки графа.
Порядок подключения DEM и опубликованных норм описан в [справочных данных](REFERENCE_DATA.md).

## Контракт последовательности

Файл содержит `values[T,C,H,W]`, Boolean-маску `valid` и метаданные прибора.
Время съёмки и готовности задаётся отдельно для каждого кадра.
Координаты, площадь пикселя и локальная сетка сохраняются.
Углы обзора, солнечный угол и размер пятна передаются явно.

Порядок физических каналов фиксируется реестром `multimodal-sensors-1`.
Реестр связывает платформу, метод калибровки, величины, единицы и нормы.
Физическая схема отделена от коэффициентов нормировки.
Кадр имеет стабильную идентичность версии и SHA256 файла.

Для МТВЗА нужны `link_pixel`, `link_cell`, `link_weight` и ссылка на происхождение весов.
Сумма весов одного пятна равна единице.
Пятна разных каналов сначала согласуются или поступают отдельными адаптерами.
Таблица пространственных связей не создаёт отсутствующую приборную диаграмму антенны.

## Подготовить данные

Используйте существующие коннекторы и численные капсулы `physical-raster-v1`.
Не применяйте шкалу повторно к готовым значениям Арктики.
Подготовьте план `multimodal-capsule-plan-1` со ссылками и хэшами каждого канала.
Отсутствующий канал обозначьте `null`.
Пустой кадр не создаёт вымышленное измерение.

```bash
python -m global_weather.multimodal prepare-capsules --plan data/capsule-plan.json --output data/sequence.npz
```

Нужны подтверждённые происхождение, калибровка и геометрия.
Старые капсулы без происхождения требуют отдельного неизменяемого подтверждения.
Это не разрешает заменить неизвестное значение догадкой.
Строковое время сканирования требует отдельного адаптера; текущий метод использует согласованные кадры.

В план выборки добавьте раздел `multimodal`:

```json
{
  "schema": "multimodal-input-1",
  "sensors": {"path": "sensors.json", "sha256": "ACTUAL_SHA256"},
  "scenes": {
    "sample-id": [{"sensor": "electro_adapter", "file": {"path": "sequence.npz", "sha256": "ACTUAL_SHA256"}}]
  },
  "radius_km": 500,
  "neighbors": 16,
  "base_channels": 16
}
```

Замените идентификаторы и хэши фактическими значениями.
Не дублируйте исходный канал одновременно в растровом и скалярном входе.
Связанные производные продукты имеют собственное обозначение, но не считаются независимыми от исходников.

## Рассчитать нормы каналов

Черновой реестр содержит `mean=null`, `std=null`, `fit_end=null` и `normalization_sha256=null`.
Рабочая модель такой реестр не принимает.
Команда рассчитывает нормы только по уникальным пригодным кадрам части `train`:

```bash
python -m global_weather.multimodal fit-sensors --dataset data/unscaled-sensors.json --output data/with-sensor-norms.json
```

Для изображений используется площадь исходного пикселя.
Для согласованных СВЧ-пятен используется вес уникального измерения.
Нулевая дисперсия вызывает отказ.
Статистики сохраняют хэши исходников, период и физическую схему прибора.
Нормы спутников не заменяют отдельный атмосферный `NormalizationBundle`.

## Обучить и проверить

Штатная фабрика создаёт `MultimodalWeatherModel`, когда манифест содержит раздел `multimodal`.
Без раздела используется прежняя адаптивная модель.
Команды `pipeline validate`, `train`, `evaluate` и `forecast` сохраняются.

Для нового аналитического испытания:

```bash
python -m global_weather.multimodal demo-dataset --output outputs/multimodal-data --horizon-hours 6
python -m global_weather.pipeline train --dataset outputs/multimodal-data/dataset.json --config configs/train_smoke.json --output outputs/multimodal-training
python -m global_weather.multimodal selftest --output outputs/multimodal-check
```

Первая команда не получает реальные наблюдения.
Последняя проверяет градиенты всех ветвей, контрольную точку и расчёт до 72 часов.
Прогнозный режим не читает будущие цели.
Недоступные кадры исключаются до любого кодирования.
При уточнении собственного фона одна версия кадра не усваивается повторно.

## Загрузка обучающих данных

```bash
python -m global_weather.multimodal plan-data --start 2020-01-01T00:00:00Z --end 2020-01-02T00:00:00Z --station 26063099999 --output plan.json
python -m global_weather.multimodal acquire --plan plan.json --output data/acquisition-01 --network --limit 4 --offset 0
```

Первая команда только формирует план.
Вторая выполняет ограниченный пакет через существующие коннекторы NOAA и CDS.
Сеть не открывается из обучающего шага.
Спутниковые загрузчики не дублируются: используются проекты приёма оператора.
Время скачивания архива не объявляется исторической готовностью наблюдения.

## Оставшиеся ограничения

Калибровка реальных СВЧ-каналов и антенные веса не получаются из структуры сети.
Обработка меняющейся геометрии проходов и строковых времён требует отдельных адаптеров.
Перенос признаков не является консервативным переносом физических величин.
Память больших сеток требуется измерять отдельно.
Многосезонная точность и полный водно-энергетический бюджет пока не подтверждены.
