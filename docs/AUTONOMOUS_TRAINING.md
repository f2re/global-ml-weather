# Автономное обучение

## Область

План: [GLOBAL-WEATHER-AUTO-1](AUTONOMOUS_TRAINING_PLAN.md).
Новый цикл получает GHCNh и ERA5, формирует выборку, рассчитывает нормы, обучает модель и выполняет отдельный итоговый тест.
Новые эксперименты используют `auto`: CUDA при доступности, иначе CPU.
Существующая очередь коротких испытаний остаётся ограниченным CPU-стендом.

Это архивное исследование, не оперативный выпуск.
Задержка поступления GHCNh задаётся явным допущением.
Время реального скачивания сохраняется отдельно.
Прогностическая точность и историческое время поступления не подтверждены.

## Установить и запустить

Используйте отдельный Python 3.10 или новее.
Не заменяйте системный Python Astra.
Установите совместимую сборку PyTorch по [официальной инструкции](https://pytorch.org/get-started/locally/).
CPU-сборка PyTorch не использует CUDA, даже при установленной видеокарте.

```bash
python -m pip install -e '.[autonomous,lab,test]'
python -m global_weather.lab.app --workspace outputs/lab --port 8765
```

Откройте `http://127.0.0.1:8765/experiments`.
Для каталога экспортированной продукции arktika-worker добавьте разрешённый корень:

```bash
python -m global_weather.lab.app --workspace outputs/lab --arktika-root /path/to/arktika-products
```

Замените пример пути своим каталогом.
Исходные продукты и службы arktika-worker не изменяются.

## Настроить источники

Вставьте персональный токен CDS в раздел доступа.
Примите условия ERA5 pressure levels и single levels в своём аккаунте CDS.
Это действие требуется выполнить владельцу аккаунта; программа не принимает юридические условия вместо него.
Можно использовать уже настроенный `.cdsapirc`.

Токены сохраняются в `WORKSPACE/autonomous/credentials.json` с правами 0600.
Они не возвращаются через API, не включаются в манифест, веса или журнал.
Защитите весь рабочий каталог правами пользователя службы.
Не публикуйте локальный стенд в интернет без отдельной системы доступа.

Для GPTL можно использовать публичный доступ или Bearer.
Для обновления токена нужны refresh token, идентификатор зарегистрированного клиента и его адрес возврата.
Вход OAuth через браузер в новом интерфейсе не реализован.
Клиентские реквизиты должны быть выданы оператором GPTL.

## Выполнить эксперимент

Выберите период, сетку, горизонт и число эпох.
Расширенные параметры задают шаг исходной ERA5, станции, разбиение, ресурсы и параметры оптимизации.
Разрешите сеть в пределах бюджета и проверьте план.
Нажмите «Запустить эксперимент».

Программа выполняет следующие действия:

1. Выбирает станции по каталогу или использует заданный список GHCNh.
2. Получает файлы за необходимые годы, проверяет схему, признаки качества и физические диапазоны.
3. Запрашивает точные сроки ERA5, все 37 уровней, часовые осадки и отдельную статику z/lsm.
4. Проверяет покрытие целей каждого срока и уровня, исключая подземные уровни по целевому давлению.
5. Формирует train, validation и test с защитными временными интервалами.
6. Импортирует фиксированные нормы GraphCast и дополняет их только обучающей частью.
7. Обучает модель и сохраняет эпохи, веса, оптимизатор, устройство и состояния генераторов.
8. Выбирает лучшую эпоху по validation и выполняет отдельный итоговый тест.

GHCNh здесь предоставляет T2, Td2, u10, v10, давление станции и MSLP.
Осадки станций не выводятся из неоднозначных накоплений.
Неполные наблюдения не заполняются реанализом.
Недостаток обязательных станций, целей или норм останавливает эксперимент.

Остановка сохраняет завершённые этапы и эпохи.
Кнопка «Продолжить» проверяет их контрольные суммы.
Незавершённая первая эпоха начинается заново; её прежний каталог сохраняется отдельно.
Неоднозначные опубликованные каталоги без паспорта требуют ручного расследования.
Повреждённый кэш не используется и не перезаписывается автоматически.

## Командная строка

Пример плана находится в `configs/autonomous_pilot.json`.
Проверка плана не скачивает метеорологические данные.

```bash
python -m global_weather.autonomous plan --plan configs/autonomous_pilot.json --output outputs/planned.json
python -m global_weather.autonomous run --plan configs/autonomous_pilot.json --output outputs/real-experiment
```

Тот же повторный вызов продолжает незавершённые этапы.
Для отдельного файла доступа используйте `--credentials /path/to/credentials.json`.
Параметры `network` и `archive_assumption_accepted` явно записаны в примере.
Проверьте их смысл перед запуском.

## Арктика-М и Электро-Л

Раздел спутников показывает экспортированные продукты разрешённого каталога arktika-worker.
Кнопка импорта принимает только продукт `channel` с подтверждёнными метаданными.
RGB и предполагаемая калибровка отклоняются при физическом импорте.

GPTL использует закреплённый транспорт arktika-worker, включая STAC, STS и подпись S3.
Просмотрите коллекции и выберите Электро-Л по ответу сервиса.
Код аппарата не угадывается по названию.
Поиск ограничен семью сутками и проверяемой пагинацией.
Подписанные ссылки сохраняются только в памяти, не передаются интерфейсу и не записываются в паспорт.

Загрузка поддерживает GeoTIFF каналов и RGB с пределом 512 МиБ на объект.
Состав, контрольная сумма, время скачивания и исходные метаданные сохраняются отдельно.
L3-мозаика и RGB не становятся исходным каналом после скачивания.

**Спутниковая загрузка пока не включается автоматически в новый цикл GHCNh + ERA5.**
Подключение к модели требует подтверждённой геометрии, калибровки, норм прибора и манифеста многомодального входа.
В интерфейсе `model_ready` остаётся false.
Навигация и получение файлов не объявляются завершённым спутниковым обучением.

## Ограничения и проверка

Период ограничен 366 сутками; каждый раздел содержит минимум два выпуска после удаления защитных интервалов.
Два выпуска позволяют проверить программу, но не обосновывают статистическую точность.
Предварительная оценка объёма не является гарантией размера ответа CDS.
Проверяйте фактическое место на диске и задавайте достаточный бюджет.

Используется float32 без AMP и распределённого обучения.
Фактическое CUDA-исполнение требует отдельного испытания на видеокарте.
Для продолжения нельзя молча менять устройство и численную среду.
CUDA-операторы могут быть недетерминированными; наличие сохранённого RNG не гарантирует побитового совпадения.
Блочное долговременное хранение вместо NPZ остаётся следующим этапом масштабирования.

```bash
python -m pytest -q
python scripts/autonomous-browser-test.py
python scripts/check_docs.py --strict
```

Настоящий фрагмент GHCNh и его исходные контрольные суммы находятся в `tests/data`.
Контрактные тесты ERA5, CUDA и STAC не подтверждают доступ персонального аккаунта или правильность реальной калибровки.
