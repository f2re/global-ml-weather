# Получение спутниковых снимков на вычислительном узле

Применяйте `GLOBAL-WEATHER-REMOTE-1` и [контракт совместимости](ECOSYSTEM.md).
Код разрабатывайте локально. Команды выполняйте на `user@10.7.88.12` в рабочей копии проверенного SHA.
Используйте отдельное окружение с `rasterio`. Не изменяйте каталоги и службы поставщиков.

## Требования

CLI использует существующий `SatelliteCatalog` и доверенные сервисы GPTL.
Перед сетевой операцией требуется `--network`.
Токены не передаются через аргументы команды.
При необходимости задайте `--credentials` с путём существующего файла `Credentials` с правами 0600.
Не переносите этот файл в Git или отчёты.

Поиск ограничен семью сутками и 1–10 страницами.
Одна загрузка ограничена 536870912 байтами. Меньший предел задайте через `--max-bytes`.
Каждый паспорт результата сохраняйте в новый файл. Существующий файл CLI не перезаписывает.

## Проверить коллекции

Следующая команда является примером ограниченной проверки каталога без загрузки снимков.
Замените пути каталогами паспорта эксперимента.

```bash
python -m global_weather.providers.satellite_cli \
  --cache data/satellite-cache collections --network \
  --output outputs/satellite-collections.json
```

Проверьте фактические коллекции и идентификаторы платформы.
Не назначайте произвольной платформе имя «Электро-Л».
Доступ к каталогу не удостоверяет право скачивания объекта.

## Сохранить поиск и получить выбранный ресурс

Команды содержат заменяемые примеры времени, коллекции и идентификатора.
Период, пределы и источник должны соответствовать паспорту эксперимента.

```bash
python -m global_weather.providers.satellite_cli \
  --cache data/satellite-cache search --network \
  --start 2026-10-01T00:00:00Z --end 2026-10-02T00:00:00Z \
  --collection VERIFIED_COLLECTION --max-pages 2 \
  --output outputs/satellite-search.json
python -m global_weather.providers.satellite_cli \
  --cache data/satellite-cache download --network \
  --search-report outputs/satellite-search.json \
  --id 00000000000000000000000000000000 --max-bytes 67108864 \
  --output outputs/satellite-download.json
```

Выберите ID из сохранённой выдачи. CLI повторяет тот же запрос перед загрузкой.
Изменение публичных метаданных ресурса блокирует скачивание.
Паспорт содержит публичные результаты и хэш запроса без URI, подписанных ссылок и секретов.
`truncated=true` означает ограниченную выдачу. Даже отсутствие усечения не удостоверяет полноту периода.

Кэш содержит неизменённый файл, `asset.json`, журнал загрузки и контрольную сумму.
Готовый кэш используется после проверки хэша поставщиком.
Время скачивания не является историческим временем оперативной готовности.

## Проверить локальные файлы

Для GPTL-кэша укажите ID скачанного ресурса.

```bash
python -m global_weather.providers.satellite_cli \
  --cache data/satellite-cache inspect-local \
  --id 00000000000000000000000000000000 \
  --output outputs/satellite-cache-check.json
```

Инспекция проверяет размер и SHA256. Она не присваивает физический допуск произвольной платформе.
Для Арктики дополнительно проверяется существующий контракт метаданных L2IR.
Геометрия, нормы и допуск модели остаются отдельными проверками.

Для готовых продуктов Арктики сначала получите локальный список.
Замените путь фактическим каталогом поставщика, доступным для чтения.

```bash
python -m global_weather.providers.satellite_cli \
  --cache data/satellite-cache --arktika-root /path/to/arktika-products \
  inspect-local --output outputs/arktika-products.json
python -m global_weather.providers.satellite_cli \
  --cache data/satellite-cache --arktika-root /path/to/arktika-products \
  import-local --id 00000000000000000000000000000000 \
  --output outputs/arktika-import.json
```

Выберите ID из списка. Импорт повторно просматривает до 200 продуктов.
При усечении списка сузьте корневой каталог до нужного неизменённого продукта.
Импорт копирует готовые файлы без изменения поставщика и повторного применения шкалы.

## Условия остановки

Остановите соответствующий этап при изменении файла, отказе доступа, неизвестной калибровке или геометрии.
Сохраните ошибку и код возврата. Исключение или таймаут не являются успехом.
Успех CLI подтверждает получение или структуру файла; обучение и точность погоды требуют отдельных испытаний.

Обязательная проверка нового CLI выполняется на узле:

```bash
python -m pytest tests/test_satellite_cli.py tests/test_ecosystem.py -q
```

Тесты с подставным клиентом проверяют программный контракт. Они не удостоверяют реальные спутниковые измерения.
