## Что исправлено

Нормы рассчитаны отдельно для давления и переменной, исключительно по измерениям train за 2021 год.
Общая средняя температура всего столба больше не используется как средняя каждого уровня.
Нормы применяются при кодировании измерений, вычислении ошибки и восстановлении физических полей.
Интерполяция выполняется по логарифму давления только между соседними поддержанными уровнями.
Неподдержанные уровни сохраняют отдельную маску; отсутствующие измерения не заменяются средними.

Влажность нормируется преобразованием `log1p(q/q_scale)` и восстанавливается через `q_scale * expm1(x)`.
Лишний положительный сдвиг softplus устранён; нулевое значение восстанавливается в ноль.
Неподдержанные элементы маскируются до экспоненты, чтобы исключить переполнение при обратном распространении.
Физический выход ограничен снизу нулём.

Вертикальное представление давления участвует в каждом шаге динамики.
Новая модель обучается с нуля: старые веса несовместимы с новыми нормами.
Ветер переводится из локальных компонент сетки в декартов вектор и затем в базис станции.
Для реконструкции исключается весь целевой профиль, а её начальный момент отделён от начатого прогноза.
Будущие измерения не добавляются в прогноз.

Постановка и ограничения закреплены в [решении 0009](decisions/0009-pressure-profile-restoration.md).
Предшествующие отрицательные результаты приведены в [аудите норм](NORMALIZATION_FLOW_AUDIT.md).

## Что предстоит оценить

Выбор эпохи выполняется только по наблюдениям validation.
После обучения автоматически предусмотрен отдельный тест по станциям со сравнением с сохранением начального анализа.
Затем замороженная модель проверяется по ранее загруженному кэшу ERA5.
ERA5 не участвует в выборе эпох, норм или гиперпараметров.

Тестовый период уже использовался в прежних опытах, поэтому его результаты будут диагностическими.
Для независимой научной приёмки необходим новый период и контролируемые сравнения отдельных изменений.
R5 и R6 различаются инициализацией и бюджетом: их сравнение не доказывает преимущество одной архитектуры.
Измеренные omega, полноценная поверхность, DEM и остальные каналы в этой модели пока не поддержаны.
Оперативный выпуск, научная приёмка, публикация main и проверка удалённого CI этим отчётом не удостоверяются.

Коммит отчёта отдельно сохраняет свидетельства; работающая модель остаётся на испытанной ревизии `0890c84`.
