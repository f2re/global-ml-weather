# Получить и применить нормы

## Назначение

Нормализация переводит физические значения в безразмерные величины:

```text
z = (x − μ) / σ
x = z · σ + μ
```

`μ` — среднее значение. `σ` — положительное стандартное отклонение.
Набор норм фиксируется до обучения и проверки.
Он не изменяется по текущему прогнозу.

Базовый источник записан в `configs/normalization_sources.json`.
Статистики GraphCast описывают глобальные средние по уровням ERA5.
Они не являются весами сети, локальными картами или месячными климатическими нормами.

## Требования перед загрузкой

Используйте отдельное окружение и разрешённый сетевой доступ.
Сохраните исходные файлы, источник, ревизию кода, лицензию и SHA256.
Ревизия GitHub не фиксирует байты файлов в отдельном облачном хранилище.

В этой ревизии численные файлы источника не получены.
Импортёр проверен на синтетических NetCDF. Не называйте эти проверки измерением реальных норм.

## Загрузить базовые статистики

1. Установите зависимости обработки данных.

```bash
python -m pip install -e '.[data]'
```

2. Загрузите статистики отдельной командой.

```bash
python -m global_weather.import_climatology \
  --download data/normalization/upstream \
  --output data/normalization/graphcast_base.json
```

Ожидаемый результат: два исходных NetCDF и JSON с нормами и происхождением.
Если загрузка или проверка завершилась ошибкой, остановите подготовку.
Не создавайте коэффициенты вместо недоступного файла.

## Импортировать локальные файлы

На сервер без сети перенесите исходные NetCDF и их проверенные контрольные суммы.

```bash
python -m global_weather.import_climatology \
  --mean data/normalization/upstream/mean_by_level.nc \
  --std data/normalization/upstream/stddev_by_level.nc \
  --output data/normalization/graphcast_base.json
```

После проверки происхождения сохраните `provenance.artifact_sha256` в отдельный JSON.
Передавайте этот файл через `--expected-hashes` при повторном импорте.
При изменении исходных байтов импорт должен завершиться отказом.
Совпадение структуры NetCDF само по себе не удостоверяет источник.

## Дополнить состав

Базовый набор содержит шесть высотных величин, T2, U10/V10, MSLP и шестичасовые осадки.
Для Td2, приземного давления и общей облачности получите собственные нормы.
Для трёхчасового шага рассчитайте нормы трёхчасовых сумм осадков.
Не делите шестичасовую `σ` на два.

Каждому физическому каналу спутника назначьте отдельную норму.
Сохраните платформу, версию калибровки и период выборки.
Яркостная температура не равна температуре воздуха, хотя обе имеют единицу K.
Нормы атмосферного профиля не заменяют нормы ИК- или микроволнового канала.

Используйте только обучающую часть архива.
`weighted_statistics(values, mask, weights)` рассчитывает среднее и отклонение с масками и весами площадей.
Ось 0 содержит выборку. Остальные оси сохраняются.
Для формы `[samples, levels]` передайте веса формы `[samples, 1]`.
Функция не выбирает годы и не проверяет происхождение за оператора.

## Контракт набора

`NormalizationBundle` содержит `schema_version=1`, `kind=global_level_zscore`, `variables` и `provenance`.

| Поле переменной | Содержание |
|---|---|
| `units` | Физическая единица |
| `mean`, `std` | Среднее и положительное отклонение |
| `pressure_pa` | Поддерживаемые давления в Па |
| `interval_hours` | Интервал накопления либо `null` |

Для поверхности используйте списки длины 1.
Для профиля используйте значения на соответствующих давлениях.
Интервал `precipitation_step` должен совпасть с шагом модели.
Интерполяция норм по `log(p)` допустима только внутри исходного диапазона.
Она не является новой независимо рассчитанной статистикой.

В происхождении укажите репозиторий, ревизию, семейство данных, лицензию, хэши и период расчёта.
Если период неизвестен, сохраните `null`.
При объединении наборов сохраните происхождение каждого компонента.
Не присваивайте всем нормам известный период только одного дополнения.

## Подключить модель

Перед примером подготовьте `grids`, `records`, `registry`, `pressure_pa` и `issue_time` через проверенные адаптеры.

```python
from global_weather.normalization import NormalizationBundle
from global_weather.observations import pack_observations
from global_weather.adaptive import AdaptiveWeatherModel

norm = NormalizationBundle.load('data/normalization/complete_era5_training.json')
obs = pack_observations(records, grids[0], pressure_pa, issue_time,
                        registry, normalization=norm)
model = AdaptiveWeatherModel(grids, obs.vocabulary,
    observation_schema=obs.schema_fingerprint, hidden=128,
    latent_slots=8, step_hours=3, normalization=norm)
```

Один набор используется для входов, обратного преобразования и масштаба ошибки.
Его отпечаток входит в схемы наблюдений, состояния и контрольной точки.
Смена норм требует совместимого нового эксперимента.
Не загружайте прежние веса с незаметно заменёнными нормами.

## Проверить независимость

Вызовите `assert_independent_test(test_start)` перед ретроспективной проверкой.
Пересечение периода расчёта норм и теста блокирует проверку.
Неизвестный период также блокирует подтверждение независимости.
Отдельно проверьте годы предварительного обучения весов.
Отсутствующее наблюдение не заполняйте климатической нормой.
