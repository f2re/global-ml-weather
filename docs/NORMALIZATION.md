# Получить и применить нормы

Нормировка использует `z=(x−μ)/σ` и обратное преобразование `x=z·σ+μ`.
Средние и положительные стандартные отклонения фиксируются до обучения.
Они не меняются по текущему прогнозу.
Маски неизвестных измерений остаются отдельными.
Для R7 пять профильных величин используют закреплённые μ/σ GraphCast по [решению 0010](decisions/0010-graphcast-fixed-normalization.md).
Остальные каналы сохраняют нормы, рассчитанные только по собственным измерениям train.

## Реальные исходные файлы

В версии 0.6 файлы GraphCast фактически скачаны и включены в репозиторий.
Расположение: `assets/normalization/graphcast/mean_by_level.nc` и `stddev_by_level.nc`.
Каждый файл имеет размер 5776 байт.
Хэши и источник записаны в `SOURCES.json` того же каталога.

Атрибуты содержат начало `1979-01-02` и конечный год `2015`.
Импортёр включает конечный год полностью как консервативную границу.
При отсутствии атрибутов период остаётся неизвестным.
Исторические отчёты прежних версий не изменяются задним числом.

Это глобальные статистики ERA5 по уровням, не веса сети и не сезонные климатические карты.
Ревизия GitHub фиксирует документацию, а SHA256 фиксирует фактические байты NetCDF.

## Импортировать без сети

Установите зависимости `data` из README.
Используйте новый путь результата.

```bash
python -m global_weather.import_climatology --bundled --output data/normalization/graphcast-base.json
```

Команда проверяет встроенные хэши и создаёт `NormalizationBundle`.
Одинаковые файлы создают одинаковый отпечаток независимо от времени запуска.
Исходные файлы доступны и после установки пакета.

Для другой локальной копии сохранён прежний явный импорт:

```bash
python -m global_weather.import_climatology --mean /path/to/mean_by_level.nc --std /path/to/stddev_by_level.nc --expected-hashes /path/to/hashes.json --output data/normalization/imported.json
```

Замените пути фактическими файлами.
`hashes.json` содержит соответствие двух имён файлов их SHA256.
Сетевая загрузка через `--download` остаётся отдельным разрешённым действием.
Импорт подходящей структуры сам по себе не удостоверяет происхождение файла.

## Дополнить набор

Базовые нормы включают шесть профильных величин на 37 изобарах, T2, U10/V10, MSLP, приземное давление и общую облачность.
Также доступны нормы температуры моря и морского льда для следующих расширений.
Их наличие не включает океанскую динамику в модель.

Для Td2 нужны собственные нормы.
Осадки GraphCast накоплены за шесть часов; трёхчасовые суммы требуют отдельного расчёта по train.
Не делите шестичасовую дисперсию на два.
Не используйте нормы временных приращений вместо норм состояния.

```bash
python -m global_weather.pipeline fit-norms --dataset data/prepared/unscaled.json --base data/normalization/graphcast-base.json --output data/prepared/normalized.json
```

Оператор сначала готовит выборку и временное разбиение.
Функция читает только обучающие значения для расчёта μ/σ.
Импортированные компоненты сохраняют происхождение и период.
Недостающие величины рассчитываются по обучающей части.
Нулевая дисперсия вызывает отказ, а не замену масштаба константой.

Спутниковая яркостная температура не равна температуре воздуха.
Каждый физический канал, платформа и версия калибровки имеют собственные нормы.
Для последовательностей применяется `multimodal fit-sensors`.
Для продукции сохраняются отдельные метод, единицы и глубина слоя.
[Порядок подготовки последовательностей](MULTIMODAL.md).

## Контракт и подключение

`NormalizationBundle` содержит `schema_version=1`, `kind=global_level_zscore`, `variables` и `provenance`.
Переменная содержит `units`, `mean`, `std`, `pressure_pa` и `interval_hours`.
Для поверхности используется скаляр, для профиля — коэффициенты на поддерживаемых изобарах.
Интерполяция по `log(p)` разрешена только внутри исходного диапазона.
Она не считается новой независимо рассчитанной статистикой.

Один атмосферный набор передаётся в скалярный кодировщик, обратное декодирование и масштаб ошибки.
Фабрика штатного обучения подключает его к адаптивной и многомодальной моделям.
Нормы каналов используются перед ResU-Net, ConvGRU и спектральным MLP.
Геометрические признаки, включая рельеф, не используют статистики температуры воздуха.

Отпечатки норм входят в схемы наблюдений, состояния и контрольной точки.
Смена коэффициентов требует нового совместимого эксперимента.
Не загружайте старые веса с незаметно изменённой нормировкой.

## Независимость проверки

`assert_independent_test(test_start)` блокирует пересечение периода норм с тестом.
Неизвестный период также блокирует подтверждение независимости.
Учитывайте максимальное входное окно, включая медленный контекст поверхности.
Отдельно проверяйте годы предварительного обучения самих весов.
Не заменяйте отсутствующее наблюдение климатической нормой.
