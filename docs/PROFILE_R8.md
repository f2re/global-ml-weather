# Профильный опыт R8

Постановка: [решение 0011](decisions/0011-seasonal-climate-context.md).
Цель — проверить пользу пространственных сезонных признаков при сохранении канонических норм GraphCast.
Этот паспорт не подтверждает загрузку, обучение или улучшение точности.
Координатор сохраняет фактический SHA, командные журналы, хэши и состояние службы отдельно.

## Данные и модель

Наблюдательные входы и цели остаются реальными измерениями IGRA.
Глобальная сфера, 12-часовая причинная история, 37 уровней и прогноз до 72 часов сохраняются.
S1 удерживает целые профили; S2 сравнивает прогноз с будущими измерениями только при обучении.
Прогнозный режим не читает будущие цели.

R8 добавляет отдельную ветвь климатических средних NOAA и календарных признаков.
Период климата — 1991–2020; полный список закреплён в [каталоге источников](../configs/seasonal_climatology_sources.json).
Минимум обеспеченности — 25 лет из 30 для каждой точки и величины.
Температура, u, v и высота имеют 17 уровней; q имеет восемь уровней до 300 гПа.
Недостающий климатический признак не удаляет реальную цель и не изменяет маски наблюдений.

Климатические значения преобразуются в согласованные физические единицы и затем в признаки относительно μ/σ GraphCast.
Нормы GraphCast остаются прежними; межгодовая климатическая STD не используется вместо погодной σ.
Физический выход остаётся результатом обученной модели, а не принудительным климатическим средним.
Архитектура `pressure-profile-seasonal-v1` начинает с новых весов.
Сохраните отдельные хэши климатического артефакта и норм GraphCast.

## Бюджет

| Параметр | Предел |
|---|---|
| Файлы NOAA | Пять файлов, ожидается 45962671 байт |
| Сеть | 64 МиБ, три попытки, 90 секунд на попытку, стадия до 30 минут |
| Эпохи и patience | 20 и 5 |
| Окна train / validation / диагностического test | 192 / 48 / 48 |
| Измерения на окно | До 2000 |
| Модель | mesh 1, hidden 32, зерно 29 |
| Оптимизатор | AdamW 0,0001; weight decay 0,01; clip 1,0 |
| Реконструкция S1 | Вес 0,25 |
| CPU и RAM | Восемь потоков; до 96 ГиБ |
| Выходы и резерв диска | До 64 ГиБ; резерв свободного диска 64 ГиБ |
| Срок | `2026-10-22T10:15:00Z` |

Устройство выбирается через auto; R8 и контрольный R7 разделяют GPU 0.
Разные каталоги имеют отдельных исполнителей; служба не останавливает R7, R5 или чужие процессы.
Это совместное исполнение ограничивает сравнение длительности эпох без учёта нагрузки GPU.
Systemd с linger сохраняет исполнение после разрыва SSH.
Собственная служба R8 допускает не более трёх попыток запуска.

## Проверка

Источник выбран по практической доступности и объёму, а не по уже доказанной точности.
Новые источники рассмотрены в [исследовательском отчёте](reviews/r8-climate-source-research.md).
Перед обучением обязательны проверки итогового SHA и допуска климатических файлов.
Выбор эпохи использует только наблюдательную validation.
После фиксации весов выполняются отдельные диагностический test и внешняя проверка ERA5.
Результаты уже просмотренных периодов не являются новой независимой приёмкой.

Неподдержанные omega, поверхность, рельеф и недостаточное покрытие измерениями остаются ограничениями.
Климатическая информация не устраняет эти ограничения и не доказывает решение всей атмосферной динамики.
