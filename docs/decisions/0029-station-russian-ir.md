# Решение 0029. ИК-кадры «Арктики-М» и «Электро-Л» для станционного прогноза

Дата 22 ноября 2026 года. Статус исследовательский.

## Источники и физический допуск

Опыт `station-satellite-russian-ir-2023-2026-pilot-1` использует численные ИК-каналы 4–10 приборов МСУ-ГС/А и МСУ-ГС.
«Арктика-М» поступает через `arktika-worker`. Для «Электро-Л» используется проверенный нативный актив, поступивший через GPTL.
Архивный опыт GOES из [решения 0028](0028-station-satellite-anomaly-pilot.md) остаётся отдельной проверкой.

Следуйте [протоколу допуска](../SATELLITE_ACQUISITION.md#подготовить-проверенные-ик-кадры).
Сохраняйте версию калибровки яркостной температуры в K, нативную маску качества, геометрию, границы съёмки и подтверждённое время готовности.
Храните исходные пиксели и доказательства происхождения вместе с опытной выборкой, вне Git.
Фактические поля ERA5 применяются только при отдельной внешней проверке.

## Проверка качества прогноза

Используйте обновление скрытого состояния из решения 0028. В момент выпуска спутниковый кодировщик переносит признаки на сферу, затем обучаемый блок применяет пространственно ограниченную поправку. Вес поправки определяется по измеренным приземным аномалиям.
Поправка в скрытом пространстве не оценивает расхождение измеренной яркостной температуры и яркостной температуры, рассчитанной из атмосферного состояния. Точность поправки на изобарических уровнях требует отдельной проверки по независимым профилям.

Оцените эффект по независимым срокам на общих станциях, целях и горизонтах. Сопоставьте спутниковый вариант с зафиксированным станционным ядром.
При совместной выборке оцените вклад каждого источника отдельным запуском с его исключением. Укажите покрытие, сезоны, число независимых погодных эпизодов и интервалы неопределённости парных различий.
Контрольная точка выбирается только по validation. Итоговый test выполняется один раз после выбора.
До подтверждения физического допуска реальных кадров и результатов отдельного test опыт остаётся исследовательским.
