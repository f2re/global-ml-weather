# Решение 0007. Интеграция наблюдательных компонентов main

Дата: 8 октября 2026 года.
Основание: поручение проверить новые изменения и продолжить реализацию.
Новая ревизия main: `37cb864`.

## Приоритет поручения

Сохраняйте [решение 0005](0005-observation-supervision.md) и [GLOBAL-WEATHER-OBS-1](../../agents/OBSERVATION_TRAINING_CONTRACT.md).
Новые документы main предлагают ERA5 как учителя S0–S1.
Это противоречит прямому поручению оператора для новых реальных опытов.
Исходная политика запрещала ERA5 в потерях, нормах, предобучении и выборе эпохи.
Исключение для фиксированных профильных норм R7 установлено [решением 0010](0010-graphcast-fixed-normalization.md).
Фактические поля ERA5 остаются запрещёнными в обучении и выборе модели.
Исходное предложение main сохраняется в истории Git.

S0 остаётся явно синтетической программной проверкой.
S1 использует удержанные реальные измерения.
S2 обучает прогноз будущих измерений; S4 проверяет зафиксированную модель.
Наличие плана S3 не подтверждает реализацию циклического обучения через C2.

## Совместимые компоненты

Интегрируйте идентичность и группы наблюдений, нормализатор неполных аэрологических профилей и пространственно-временной оператор.
Индекс станции не обязателен для физического измерения; архивный API может требовать каталожный идентификатор.
Сохраняйте реальные сроки и положения каждого уровня, отдельные маски величин и запрет экстраполяции.

Станционный R3 продолжает обучение на прежней испытанной ревизии в своей рабочей копии.
Новые исходники не переключаются под работающим процессом.
Новый профильный опыт получает отдельный каталог, паспорт, веса и службу.

## Ограничения профильного опыта

IGRA не даёт автоматически omega в Па/с.
Не подставляйте скорость подъёма зонда или реанализную цель вместо этой величины.
Отсутствующий физический выход имеет явную маску и блокирует полную научную приёмку.

Первый профильный опыт использует геометрическое приближение [решения 0006](0006-station-native-pilot.md).
Независимый DEM, маска суши и физический допуск поверхностных приборов остаются требованиями полной модели.
Обучение частичных профилей и программные проверки не подтверждают качество всех уровней и регионов.
