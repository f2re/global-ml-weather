# Решение 0021. Контур ассимиляции данных российских спутниковых группировок

Дата: 18 октября 2026 года.
Основание: поручение оператора о построении контура ассимиляции данных «Электро-Л», «Арктика-М» и «Метеор-М».
Усвоение спутниковых наблюдений строится на минимизации гибридного функционала потерь.
Контур объединяет прогностические переменные ядра и спутниковые измерения с коррекцией смещений VarBC.

## Физико-математический аппарат

1. Минимизируется гибридный функционал с контролем гидростатического баланса и коррекцией смещений VarBC.
2. Для КА «Арктика-М» вычисляется нестационарная орбитальная геометрия на высокоэллиптической орбите «Молния».
3. Бесшовное композитирование полей ГСО и ВЭО использует взвешивание по оптической массе и уширению пятна.
4. Отсечение перигейного участка ВЭО оставляет рабочее окно плюс-минус 3.2 часа вокруг апогея.
5. Для ИК-каналов МСУ-ГС выполняется обращение функции Планка с калибровкой GSICS по ИКФС-2.
6. Для 29 каналов МТВЗА-ГЯ применяется всепогодная модель ошибки с симметричным индексом облачности.
7. Для ИКФС-2 выполняется сжатие спектра через 32 главные компоненты и маскирование под облаками.

## Архитектурные модули контура

1. Модуль `global_weather/multimodal/ru_sat_msugs.py` реализует адаптер сшивки и геометрический FiLM-блок.
2. Модуль `global_weather/analysis/observation_operator.py` дополнен операторами ИКФС-2, МТВЗА-ГЯ и блоком VarBC.
3. Модуль `global_weather/losses.py` дополнен робастным функционалом `SatelliteAssimilationLoss`.
4. Модуль `global_weather/connectors/raster_bridge.py` содержит расчет геометрии визирования орбиты «Молния».
5. Модуль `global_weather/products/algorithms.py` вычисляет облачную маску пятен ИКФС-2 и полярные ветры AMV.
6. Реестр `configs/observation_normalization_catalog.json` зафиксировал радиометрические нормы каналов.

## Допуск и этапы обучения

1. Стадии S1–S3 переводят модель от радиометрического прогрева к всепогодной СВЧ-ассимиляции.
2. Переход к полномасштабному обучению на `mesh8` требует прохождения обязательных тестов допуска.
3. Процедура верификации вычисляет зональные метрики RMSE для арктического пояса 60–90 градусов с.ш.
4. Экспорт валидационных прогнозов осуществляется в стандартном метеорологическом формате GRIB2.
