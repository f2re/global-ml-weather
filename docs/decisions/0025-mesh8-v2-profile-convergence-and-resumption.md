# Решение 0025. Модификация физической функции потерь Mesh-8 v2 и возобновление обучения с контрольной точки 3300 до 4500 эпох

Дата: 2 ноября 2026 года.  
Эксперимент: `joint-mesh8-training-4500` / роль: `mesh8_research_training`.  
Статус: **научно-техническая модификация целевой функции профиля, откат к оптимуму эпохи 3300 и продолжение обучения до 4500 эпох**.

## 1. Обоснование и результаты научно-технического аудита

1. В ходе цикла обучения модели Mesh-8 (0..4000 эпох) приземная ошибка `val_surface` монотонно снизилась с 0.13031 до 0.11856 (-9.0%), а общая потеря `train_loss` снизилась на -33.1% (до 0.06561).
2. На суточных и многосуточных горизонтах (+24ч, +48ч, +72ч) достигнуто радикальное улучшение: ошибка геопотенциала $\Phi$ снизилась на 38–42%, а дрейф струйного течения зонального ветра $u$ сократился почти в 2 раза.
3. Научный аудит выявил следующие структурные ограничения первой версии профильного лосса:
   - **Вертикальная дипольная компенсация**: глобальное усреднение знакового смещения $(\overline{\text{bias}}_v)^2$ по всему столбу позволяло модели компенсировать ошибку тропосферы противоположной ошибкой стратосферы;
   - **Диспаритет вертикальной квадратуры**: массовая толщина $\Delta p_k$ выделяет верхней стратосфере ($p \le 30\text{ гПа}$) лишь 3.78% веса, тогда как в барометрической формуле геопотенциала $\Phi = \int R_d T_v \, d\ln p$ эти слои формируют 52.9% интеграла, вызывая рассинхронизацию между $T$ и $\Phi$;
   - **Скалярная независимость компонент ветра**: раздельная оптимизация $u$ и $v$ приводила к росту ошибки меридионального ветра $v$ на ранних горизонтах.
4. В интервале 2100..4000 эпох глобальный минимум валидационной профильной ошибки был достигнут на **эпохе 3300 (`val_profile = 0.55840`)**, после чего на эпохах 3500..4000 наблюдалось переобучение.

## 2. Модификации физической функции потерь (Mesh-8 v2)

1. **Поуровневый робастный штраф за систематический дрейф (`bias_mode = 'level_charbonnier'`)**:
   - смещение вычисляется отдельно для каждого изобарического уровня с гейтом минимального числа измерений $N \ge 3$;
   - применяется гладкая робастная функция Charbonnier/pseudo-Huber $\Phi(b) = \delta_b^2 (\sqrt{1 + (b/\delta_b)^2} - 1)$ с $\delta_b = 1.0$;
   - уровень регуляризации скорректирован до $\lambda_{\text{bias}} = 0.15$ для предотвращения полусуточного раскачивания траектории.
2. **Гибридная вертикальная квадратура (`quadrature_mode = 'hybrid'`)**:
   - для температуры $T$ и геопотенциала $\Phi$ применяется сбалансированное взвешивание $0.50 \Delta p / \sum \Delta p + 0.50 \Delta \ln p / \sum \Delta \ln p$ с демпфированием слоев выше 20 гПа;
   - для влажности $q$ и ветра $u, v$ сохраняется преобладание массового слоя $0.85 \Delta p + 0.15 \Delta \ln p$.
3. **Изотропная 2D-связка компонент горизонтального ветра (`coupled_wind_loss = true`)**:
   - при наличии спаренных измерений $u$ и $v$ ошибка минимизируется по евклидовой длине вектора невязки скорости $\sqrt{r_u^2 + r_v^2}$, исключая размен компонент.
4. **Объективная валидация (`profile_raw`)**:
   - функция оценки `score()` возвращает как регуляризованный лосс, так и чистый unpenalized Huber-лосс для сопоставимости метрик во времени.
