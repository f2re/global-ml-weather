# Решение 0020. Многоэпошное исследовательское обучение Mesh-8 (500 эпох)

Дата: 16 октября 2026 года.  
Эксперимент: `joint-mesh8-training-500` / роль: `mesh8_research_training`.  
Статус: **исследовательское многоэпошное обучение; научная приёмка качества погоды требует отдельного длительного тестирования**.

## Причина решения

Этап R10 (`joint-mesh8-qualification-r10`) успешно подтвердил сквозную техническую работоспособность модели высокого разрешения (~28 км, 655 362 ячейки) с рельефом DEM 30s (~896 МБ) и реальными наблюдениями (IGRA2 + GHCNh). Получен статус `r10_q4_q5_technically_qualified`.

По распоряжению оператора инициируется полномасштабный процесс обучения на 500 эпох с целью оптимизации весов и уменьшения ошибки прогноза.

## Ограничения и параметры

1. **Роль и границы**:
   - Роль `mesh8_research_training` отделена от квалификационной роли `mesh8_end_to_end_qualification` (которая строго сохраняет `epochs: 1` для воспроизводимости гейта R10).
   - Лимит эпох: до 1000 (в конфигурации `configs/joint_observation_training_mesh8_500.json` установлено `epochs: 500`).
   - Ранняя остановка (`patience`): 50 эпох без улучшения валидационной ошибки `joint`.

2. **Сохранение памяти и физики**:
   - `mesh_level: 8` (655 362 ячейки, средний масштаб 27,9 км);
   - `rollout_hours: 3` (сохраняет измеренное потребление VRAM в пределах 24 ГБ);
   - `hidden: 4` (подтверждённая ширина latent-состояния, 903 обучаемых параметра);
   - `edge_chunk_size: 32768` (чанкование рёбер графа для предотвращения OOM);
   - Вычислительное устройство: `cuda:0` (NVIDIA GeForce RTX 4090 24 ГБ).

3. **Оптимизация цикла**:
   - Список сроков с полным покрытием IGRA2 (`supported_issues`) кэшируется перед циклом эпох, исключая многократное сканирование дискового массива на каждой эпохе.

4. **Выходы**:
   - Рабочий каталог на сервере: `outputs/mesh8-500-run/training`.
   - Журнал процесса: `outputs/mesh8-500-run/training/progress.json`.
