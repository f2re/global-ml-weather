# Экспорт исследовательского прогноза в GRIB2

Экспортёр сохраняет физические профильные поля замороженного прогноза.
Он создаёт международный контейнер GRIB2 и отдельный паспорт полей.
Совместимость контейнера не подтверждает точность погоды или готовность оперативного выпуска.

## Требования

В отдельном окружении вычислительного узла нужны Python-пакет `eccodes>=2.38,<3` и библиотека ecCodes.
Пакет входит в дополнительную зависимость `grib` проекта.
Установка пакетов с загрузкой требует разрешения на сеть.
Таблицы ecCodes должны содержать стандартные параметры WMO, перечисленные ниже.

Входные файлы: `forecast.npz` и `forecast.json` от замороженного профильного прогноза.
Схема входа: `measured-profile-frozen-forecast-1`.
Экспортёр также принимает `unified-research-forecast-1` с явными названиями, единицами и базисом ветра.
Экспортёр проверяет SHA256, физические единицы, порядок величин, сферические координаты, маски и сроки.
Он не читает будущие цели и не меняет исходные файлы.

## Команда

Запустите команду на вычислительном узле после передачи зафиксированной ревизии Git.
Пути в команде служат заменяемыми примерами.

```bash
python -m global_weather.grib_export --forecast outputs/frozen-forecast --output outputs/products/forecast.grib2 --spacing-degrees 5
python -m pytest tests/test_grib_export.py -q
```

Параметр `--spacing-degrees` задаёт шаг сетки продукции.
Допустимый шаг: от 0,25 до 90 градусов; он должен делить 180 и 360 градусов.
Шаг продукции не меняет разрешение нейросети.
Проверка полного цикла с ecCodes обязательна для приёмки GRIB2.
Её пропуск из-за отсутствия дополнительной зависимости блокирует приёмку формата.

## Кодирование

Экспортёр использует дисциплину 0, шаблон сетки 3.0 и шаблон продукта 4.0.
Изобарическая поверхность имеет код 100; значение давления хранится в Па.
Все 37 изобар сохраняются от 1000 до 1 гПа.
Начальный срок содержит UTC, включая секунды; заблаговременность задана в часах.
Срок действия равен сумме начального срока и заблаговременности.
Каждая величина, изобара и срок образуют отдельное сообщение.

| Величина | Категория | Номер | Единица |
|---|---:|---:|---|
| Температура воздуха | 0 | 0 | K |
| Удельная влажность | 1 | 0 | kg kg-1 |
| Восточная составляющая ветра | 2 | 2 | m s-1 |
| Северная составляющая ветра | 2 | 3 | m s-1 |
| Геопотенциал | 3 | 4 | m2 s-2 |
| Вертикальная скорость в координате давления | 2 | 8 | Pa s-1 |

Геопотенциал не превращается в геопотенциальную высоту.
`omega` не превращается в геометрическую вертикальную скорость.
Пропуски сохраняются через bitmap; неподдержанная величина образует сообщение без пригодных точек.
Экспортёр не заполняет пропуски нормой, ISA или реанализом.

Статус данных: исследовательский продукт, код 2.
Центр по умолчанию отсутствует: двухбайтовое значение 65535.
Экспортёр не приписывает модель ECMWF, NOAA или другому центру.
Параметры `--centre` и `--subcentre` допускают только подтверждённый оператором идентификатор.
Идентификатор процесса остаётся отсутствующим; паспорт JSON сохраняет модель и контрольную точку.
Неформальный идентификатор не заменяет регистрацию центра для международного оперативного обмена.

## Сетка и маски

Сетка продукции покрывает земной шар центрами широтных полос без дублирования полюсов.
Порядок точек: долгота возрастает от 0; широта убывает с севера на юг.
Экспортёр берёт ближайшую ячейку исходной сферической сетки.
Это точечная выборка; она не сохраняет интеграл по площади и не добавляет пространственной информации.

Ветер переносится вдоль короткой дуги большого круга в касательную плоскость точки продукции.
После переноса экспортёр получает восточную и северную составляющие в локальном базисе.
Маска ветра требует обе исходные составляющие; отсутствующее измерение не заменяется нулём.
Радиус сферы в GRIB2 совпадает с радиусом модели: 6371008,8 м.

Экспортёр использует самостоятельную маску выдачи каждого профильного поля.
Он не переопределяет маски наблюдений, целей или подземных уровней.
Для совместной станционной схемы экспортёр сохраняет только давление на уровне моря.
Код поля: дисциплина 0, категория 3, номер 1; поверхность 101.
Выборка ближайшей станции ограничена радиусом `--station-radius-km`, по умолчанию 50 км.
Точки за пределами поддержки остаются пропусками.
Такая выборка не является глобальным анализом давления.
Станционное давление исключено: высоты земли станции и точки продукции могут различаться.
Его экспорт требует отдельного физического переноса давления с учётом высоты.
Температура и ветер станции исключены: высота датчика над землёй неизвестна.
Осадки исключены: схема не задаёт интервал накопления.
Для прежней профильной схемы приземные поля не экспортируются.

В текущем совместном опыте профильная голова не получила наблюдательного обучения.
Её маска выдачи ложна для всех точек; соответствующие сообщения GRIB2 содержат только пропуски.
Диагностические значения этой головы не становятся пригодным прогнозом после экспорта.

## Выход и ограничения

Выход состоит из `forecast.grib2` и `forecast.grib2.json`.
Паспорт содержит описание сообщений, единицы, сроки, число пригодных точек и SHA256.
Он также сохраняет происхождение контрольной точки, версию ecCodes и метод переноса на сетку продукции.
Существующий результат не перезаписывается.
Несовпадение хэша, единиц, геометрии, сроков или масок останавливает экспорт.

Синтетическое декодирование проверяет структуру, метаданные, порядок точек и пропуски.
Отдельно требуется проверка сторонним потребителем GRIB2 и научная приёмка реального прогноза.
Экспорт не создаёт регистрацию WMO, транспорт GTS/WIS2 или соглашение с принимающим центром.
