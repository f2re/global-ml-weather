# Коннекторы данных

Реестр: global_weather/connectors/__init__.py. Все сетевые возможности
отделены от сервера испытаний; без явного --network загрузка не выполняется.
Данные приходят в промежуточное хранилище, не непосредственно в обучающий тензор.

| Источник | Реализовано | Ещё требуется |
|---|---|---|
| Станции/аэрология JSONL | Инспекция контракта, единиц как метаданных, времени и пропусков | Независимый QC и операторы наблюдения |
| SatDump | Инвентаризация и карантин CBOR/прочих файлов | Декодеры, радиометрия, геопривязка, антенные пятна |
| GraphCast ERA5 | Ограниченная HTTPS-загрузка, SHA256; существующий импортёр μ/σ | Проверка реальных байтов, периода и недостающие нормы |
| NOAA ISD | Годовой CSV, QC T/Td/ветра/MSLP, конверсия в JSONL | Высоты датчиков, согласование дублей, историческая доступность |
| ERA5 CDS | Запрос на дату и отдельное выполнение cdsapi | Ключ, принятие условий, целевые поля на нашей сетке |
| Электро/Арктика | Локальный манифест и инспекция | Реальный геопортальный API и права доступа |

```bash
python -m global_weather.connectors.acquire graphcast --network --output data/norms
python -m global_weather.import_climatology --mean data/norms/mean_by_level.nc \
  --std data/norms/stddev_by_level.nc --output data/graphcast_base.json

python -m global_weather.connectors.acquire noaa-isd --network \
  --station 26063099999 --year 2020 --output data/isd.csv

python -m global_weather.connectors.acquire era5-request \
  --date 2020-01-01 --output data/era5-request.json
# Явное выполнение после принятия условий CDS и настройки ключа вне проекта:
python -m global_weather.connectors.acquire era5-download --network \
  --date 2020-01-01 --output data/era5-pressure.nc
# Для поверхности добавить --surface.
```

Пример идентификатора NOAA не удостоверяет наличие конкретного архива.
Конвертер не выводит осадки из случайных групп и не делит накопления на часы.
Ветер переводится из метеорологического направления «откуда». Без направления
используется только штиль. Значения с непригодным QC пропускаются. Варианты
дублирующих сообщений требуют согласования, не усредняются молча.

available_at архива — время его загрузки. Для реконструкции оперативного
выпуска нужен внешний журнал доступности либо явно обозначенное предположение.
Номинальные высоты наземных величин требуют проверки метаданных станции.

Каждый скачанный файл сохраняет sidecar с URL, SHA256, временем и флагом
content_verified=false. Успешное скачивание не означает физическую пригодность.
Публичный загрузчик допускает только два закреплённых хоста HTTPS, ограничивает
объём, не следует междоменным перенаправлениям и не перезаписывает файлы.
Вызов CDS использует официальный клиент отдельно; проверяйте объём запроса и
квоты до выполнения. Пример дня глобальных 37 уровней — не малая загрузка.

Сетевые загрузки в среде разработки 0.3 не выполнены. Проверены локальные
контракты и синтетические файлы; результат проверки сети не выдумывается.
Документация: https://cds.climate.copernicus.eu/how-to-api и
https://www.ncei.noaa.gov/products/land-based-station/integrated-surface-database .
