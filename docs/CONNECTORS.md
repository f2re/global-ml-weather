# Коннекторы данных

## Назначение и ограничения

Реестр находится в `global_weather/connectors/__init__.py`.
Коннектор получает или читает данные. Он не подтверждает автоматически их физическую пригодность.

Сетевая загрузка отделена от веб-стенда.
Для команд получения данных требуется явный `--network`.
Импорт существующих локальных файлов не создаёт новый сетевой клиент.

| Источник | Реализовано | Требуется для следующего этапа |
|---|---|---|
| Станции и аэрология JSONL | Проверка структуры, времени и масок | Независимый контроль качества |
| SatDump `release/1.2.2` | Родные контейнеры, ссылки, раскладки и отчёты | Радиометрия, геометрия и антенный оператор |
| GraphCast / ERA5 | Загрузка статистик, хэши и импорт норм | Реальные файлы, период и недостающие нормы |
| NOAA ISD | Годовой CSV; T, Td, ветер и MSLP с признаками качества | Высоты датчиков, дубли и историческая доступность |
| ERA5 CDS | Запрос на дату и отдельная загрузка | Доступ оператора и подготовка целей |
| `arktika-worker` | Численные каналы и маска качества | Проверенная геометрия и нормы канала |
| GPTL | Локальный L2IR, STAC или нормализованный объект | Подтверждённый канал и журнал загрузки |

Сетевые загрузки не испытаны на реальных данных в этой ревизии.
Статус карточки описывает реализацию, а не наличие действующего подключения.

## Получить статистики GraphCast

```bash
python -m global_weather.connectors.acquire graphcast --network --output data/norms
python -m global_weather.import_climatology --mean data/norms/mean_by_level.nc \
  --std data/norms/stddev_by_level.nc --output data/graphcast_base.json
```

Ожидаемый результат: исходные файлы, журналы получения и базовый набор норм.
Полный порядок проверки приведён в [нормализации](NORMALIZATION.md).

## Получить архив NOAA

Проверьте существование идентификатора станции и выбранного года до загрузки.
Следующая команда содержит пример идентификатора, а не подтверждение доступности архива.

```bash
python -m global_weather.connectors.acquire noaa-isd --network \
  --station 26063099999 --year 2020 --output data/isd.csv
```

Конвертер учитывает признаки качества температуры, точки росы, ветра и MSLP.
Направление ветра означает направление, откуда он дует.
Без направления допускается только штиль.
Дубли сообщений требуют отдельного согласования.
Осадки не выводятся из неподтверждённых групп и не делятся на произвольные часы.

Архивный CSV не доказывает историческое время доступности.
Время загрузки архива не подменяйте временем оперативного поступления.
Для исторического выпуска нужен внешний журнал либо явно обозначенное предположение эксперимента.
Проверьте номинальные высоты датчиков по метаданным станции.

## Подготовить запрос ERA5

Перед загрузкой настройте `cdsapi` и доступ вне репозитория.
Примите условия набора в CDS. Оцените объём и квоты.
День глобальных данных на 37 уровнях не является малым запросом.

```bash
python -m global_weather.connectors.acquire era5-request \
  --date 2020-01-01 --output data/era5-request.json
```

Команда создаёт описание запроса без загрузки.
Для явной загрузки выполните:

```bash
python -m global_weather.connectors.acquire era5-download --network \
  --date 2020-01-01 --output data/era5-pressure.nc
```

Для приземных данных добавьте `--surface`.
Реанализ служит целями и основой норм. Он не заполняет пропуски оперативных наблюдений.

## Принять продукты пользователя

Используйте существующие каталоги загрузки и приёма только для чтения.
Не изменяйте `.ready`, `.download.json`, настройки и службы поставщика.
Порядок работы с Арктикой, «Электро-Л» и SatDump: [совместимость](ECOSYSTEM.md).

## Правила получения

Публичный загрузчик допускает только закреплённые HTTPS-хосты.
Он ограничивает объём и не следует междоменным перенаправлениям.
Существующий файл не перезаписывается.
Журнал содержит URL, SHA256, время и `content_verified=false`.
Успешная загрузка не подтверждает физическую пригодность.

Клиент CDS выполняется отдельно от публичного загрузчика.
Не передавайте его ключи через интерфейс стенда.
При ошибке, неизвестном формате или несовпадении хэша остановите затронутый этап.

Источники: [NOAA ISD](https://www.ncei.noaa.gov/products/land-based-station/integrated-surface-database),
[CDS API](https://cds.climate.copernicus.eu/how-to-api).
