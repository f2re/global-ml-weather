# Проверки стенда 0.3

Дата подготовки: 3 октября 2026 года. Результаты погоды не измерялись.

## Выполнено локально

Новые компоненты проверены поверх доступного локального архива модели 0.1;
адаптивное ядро 0.2 сохранено непосредственно из актуальной ветки GitHub, а не
заменено старым архивом. Локальный набор: 97 passed, 1 skipped; из 42 новых
случаев 41 выполнен, один интеграционный тест адаптивного ядра ожидает полную
копию исходников в GitHub Actions. Пропуск назван явно, это не успешный тест.

Проверены API, очередь, ограничения параметров, отмена и таймаут, состояния
после перезапуска, Host/Origin/CSRF, имена/символические ссылки, загрузка без
перезаписи, конфликт двух загрузок, реальный процесс baseline, поля и профили,
инспекция JSONL и карантин, метрики по маскам/площади, NOAA QC/ветер, запрос ERA5,
ограничения URL без сети, реестр ролей и исполнение планирования данных.

compileall, синтаксис app.js и сборка wheel выполнены. Статические ресурсы
включены в пакет. Загружаемые в GitHub новые поддеревья сверены с локальными
Git tree SHA; исходное ядро 0.2 осталось неизменным.

HTML/CSS/JS проверены в Chromium с фактическим локальным HTTP backend через
тестовый транспорт страницы. Прямой переход браузера на URL был заблокирован
политикой среды; политика не изменялась. Протестированы baseline до +72 ч,
поле/уровень/срок, вкладки, протокол, ширина 390 px: ошибок JavaScript и
горизонтального переполнения не обнаружено. Это не заменяет обычную навигацию
и проверку CSP в полноценном браузерном запуске CI.

## Полная проверка на GitHub

.github/workflows/tests.yml запускает полное дерево проекта: Python 3.11/3.13,
явный импорт AdaptiveWeatherModel до pytest, все 134 случая, два синтетических
расчёта до +72 ч. Отдельное задание Chromium использует обычное HTTP-подключение
без тестового транспорта: адаптивная модель, поля/профиль/таймлайн, загрузка
файла, все девять ролей, протокол и мобильная ширина. Снимки сохраняются
артефактом lab-browser-screenshots.

Фактический статус удалённых заданий следует проверять по commit SHA: этот
документ описывает настроенные проверки и не объявляет их завершёнными заранее.

## Не выполнено

Нет живой проверки внешних загрузок, радиометрической проверки спутниковых
файлов, обучения на наблюдениях, оценки независимой точности и теста промышленной
безопасности. Наличие инструкций не является независимой рецензией LLM-агентов.
