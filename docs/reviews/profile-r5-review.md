# Независимая рецензия исправлений R5

Дата: 9 октября 2026 года. Роль исполнителя: `verification`, Python-рецензент.

## Область

Проверены изменения профильного обучения, отдельной проверки ERA5 и диспетчера R5.
Применены OBS-1, OBSERVATIONS-1, TRAIN-1, REMOTE-1 и протоколы проекта.
Применён навык `python-patterns`.
Рецензент не изменял проверяемый код и не запускал расчёты локально.

## Исходные замечания

[HIGH] Неполная проверка совместимости исходников при переносе состояния.
Файл: `global_weather/profile_training.py`, функция `_model_definition_sha256`.
Исходная проверка учитывала только AST класса модели.
Изменение оператора наблюдений, геометрии или функции потерь могло пройти этот допуск.
Требование: проверить определения подготовки данных, модели, потерь и зависимые модули.

[HIGH] Командный интерфейс не передавал параметры нового опыта.
Файл: `global_weather/profile_training.py`, функция `main`.
Диспетчер R5 использовал отсутствующие параметры `--continue-from` и `--parent-commit`.
Требование: добавить параметры и передать их явно, сохранив строгую проверку обычного продолжения.

[HIGH] Новая ревизия не могла проверить прежнюю модель R4.
Файл: `global_weather/profile_training.py`, функция `load_model`.
Строгое соответствие SHA блокировало отдельное сравнение старой контрольной точки после исправления проверяющего кода.
Требование: отдельный явный допуск прежнего SHA с проверкой совместимости вычислений.
Обычное продолжение обучения не должно получать такой обход.

[HIGH] Паспорт проверки не поддерживал список файлов NetCDF.
Файл: `global_weather/profile_verification.py`, функция `_identity`.
Модуль получения ERA5 передаёт списки суточных файлов.
Требование: сохранить порядок, пути и хэши каждого файла в паспорте.

## Повторная статическая проверка

Все четыре замечания HIGH устранены в повторно прочитанных исходниках.
Проверка совместимости теперь включает неизменённые определения, константы и импорты тренировщика.
Она также включает исходные файлы геометрии, графовой модели, вертикали, времени и оператора наблюдений.
Из сравнения исключены только явно изменённые функции управления и новые стандартные импорты `ast` и `re`.

CLI передаёт оба параметра переноса.
Обычная загрузка сохраняет строгое соответствие SHA.
Отдельная загрузка замороженных весов допускает переход SHA только при совместимом вычислении и неизменной численной идентичности.
Паспорт ERA5 сохраняет упорядоченные пути и SHA256 каждого суточного файла.

Продолжение проверяет родительскую контрольную точку, завершение и ссылку `latest.json`.
AdamW и генераторы случайных чисел восстанавливаются вместе с весами.
Родительские файлы не перезаписываются.
Диспетчер R5 сравнивает фактическое окружение с паспортом R4, включая пакеты и драйвер ускорителя.

Статус статической рецензии: Warning; новых CRITICAL или HIGH не обнаружено.

[MEDIUM] Сложность функций управления.
Файл: `global_weather/profile_training.py`, функция `_initialize_continuation`.
Функция имеет семь аргументов и объединяет несколько проверок происхождения.
Исправление: выделить типизированный контекст продолжения при следующем рефакторинге с сохранением контрактных тестов.

Добавлены тесты сохранения шага AdamW, неизменности родителя, отказа при дрейфе, повторного использования проверки и повреждения артефактов.
Тест COO-сравнения содержит отдельный сценарий CUDA.
Прочитаны определения тестов; рецензент не утверждает их успешное исполнение.

## Вывод и ограничения

По исходникам исправления пригодны для обязательных удалённых испытаний.
Инженерная приёмка требует успешных обязательных команд на зафиксированной ревизии.
Сравнение разреженных COO-тензоров сохраняет индексы и значения без уплотнения.
Неизвестный формат тензора вызывает отказ.
Завершённая проверка получает паспорт и хэши; незавершённые файлы сохраняются отдельно.
Эти свойства проверены по исходникам, а не по фактическому расчёту ERA5.

R5 остаётся новым опытом с перенесёнными весами, AdamW и генераторами случайных чисел.
Повтор прежнего test является диагностикой.
Рецензия не подтверждает точность погоды, независимость ERA5 или полную научную приёмку модели.
