## Решение по допуску

**`BLOCKED` для реальной спутниковой ассимиляции и её оперативного выпуска.**
Текущая цепочка S1–S3 реализует программный эксперимент с синтетическими спутниковыми входами и целями.
Код этапов читает наземную выборку, климатологию и начальные веса.
У команд запуска отсутствует вход для архива спутниковых наблюдений.

## Получение спутниковых файлов

Закреплённая ревизия `arktika-worker` — `4d744570653ac60c8fd059d10e617c3806a6bafc`.
Для SatDump закреплена ветка `release/1.2.2` и ревизия `394431e11d9fffe1a73d3e0670fb023ad7562241`.
В реестре проверка установленного бинарного файла и испытание реальных кадров имеют значение `false`.
[Реестр поставщиков](../../configs/ecosystem_sources.json).

Штатный CLI `global_weather.providers.satellite_cli` поддерживает ограниченный поиск, загрузку и проверку локального кэша.
Инспекция проверяет размер и SHA256, а для L2IR Арктики также проверяет физические метаданные.
В отчётах инспекции и импорта остаётся `model_ready=false` до проверок геометрии и норм.
[Команды получения](../SATELLITE_ACQUISITION.md), [инспекция](../../global_weather/providers/satellite_cli.py#L101-L146), [импорт](../../global_weather/providers/satellites.py#L177-L195).

Старый конвейер `run_remote_acquisition.sh` включает загрузку спутников через отдельный проверочный скрипт.
Этот скрипт принимает URI из каталога и считает локальный файл готовым по порогу размера.
Фоновый конвейер перехватывает исключения загрузки и может записать общее сообщение об успехе после ошибки.
Для автономной загрузки используйте штатный ограниченный CLI.
[Команда старого конвейера](../../scripts/run_remote_acquisition.sh#L14-L23), [проверочный скрипт](../../scripts/fetch_arktika_worker_data.py#L95-L121), [обработка ошибок](../../scripts/run_dataset_pipeline_background.py#L122-L159).

## Условия допуска реального опыта

1. Проверьте на вычислительном узле реальные файлы и ревизии поставщиков.
2. Сохраните для каждого канала калибровку, единицу, геометрию, антенное пятно при необходимости, маску качества, версию и SHA256.
3. Зафиксируйте время наблюдения и время готовности каждого кадра по подтверждённым источникам.
4. Рассчитайте спутниковые нормы по уникальным кадрам обучающей части.
5. Проверьте привязку оператора к координатам, вертикали и сроку измерения.
6. Проверьте причинность входов, отдельные маски каналов и защиту от повторного усвоения версии.
7. Выберите контрольную точку на валидационной части и проверьте совместимость продолжения после прерывания.
8. На зафиксированных весах выполните отдельный тест прогноза на общих целях с контрольным прогнозом.

Неизвестная калибровка, геометрия или готовность наблюдения блокирует затронутый источник.
Поля ERA5 допустимы только в отдельной проверке зафиксированной модели.
Для выпуска требуются обязательные проверки итогового SHA и отдельная научная приёмка.
