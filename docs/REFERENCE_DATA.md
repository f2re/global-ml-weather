# Нормы реанализа и глобальный рельеф

## Фактически полученные данные

Версия 0.6 включает реальные численные статистики GraphCast в Git.
Глобальный DEM скачан отдельно через GitHub Actions.
Данные не являются весами обученной погодной нейросети.
Ни скачивание, ни успешный тест программы не подтверждают точность погоды.

| Ресурс | Параметры | Размещение |
|---|---|---|
| GraphCast mean/std | По 5776 байт; 37 изобар и приземные переменные | `assets/normalization/graphcast/` |
| GMT Earth Relief | 30 угловых секунд; 43200 × 21600; 288 исходных плиток | Артефакт GitHub Actions |
| Собранный DEM | 896166188 байт; int16; шаг упаковки 0,5 м | `earth_relief_30s_p.nc` |
| Архив DEM | 896259259 байт | Также меньше 900000000 байт |

Все размеры здесь заданы в байтах и десятичных мегабайтах.
DEM занимает 896,17 МБ и соответствует пределу пользователя.
Большой массив не добавляется в историю Git.

## Какие нормы включены

Исходные файлы получены из официального хранилища GraphCast.
Их адреса, SHA256 и ревизия документации указаны в `assets/normalization/graphcast/SOURCES.json`.
Файлы хранят глобальные средние и стандартные отклонения.
Это не локальные месячные климатические поля.
Для [R8](PROFILE_R8.md) пространственная сезонная климатология подключается отдельным адаптером по [решению 0011](decisions/0011-seasonal-climate-context.md).
Она использует готовые месячные средние NOAA NCEP1 за 1991–2020; погодные μ/σ GraphCast остаются неизменными.
Список пяти ресурсов и порог 25 пригодных лет закреплены в [каталоге](../configs/seasonal_climatology_sources.json).
Фактические пути, SHA256 и результаты получения сохраняются в отчёте исполнения опыта.

Атрибуты обоих файлов содержат `date_start=1979-01-02` и `date_end=2015`.
Импортёр трактует конечный год консервативно: до конца 31 декабря 2015 года включительно.
Он не выдумывает точное время последнего исходного наблюдения.
Периоды среднего и стандартного отклонения обязаны совпадать.

Формула нормировки: `z = (x − μ) / σ`.
Обратное преобразование: `x = z · σ + μ`.
Для профилей коэффициенты выбираются по величине и давлению.
Маска отсутствующего измерения остаётся отдельной.

Опубликованные файлы также содержат приземное давление и общую облачность.
Прежнее предположение об их отсутствии исправлено после чтения реальных данных.
Включены доступные нормы температуры моря и морского льда для последующих расширений.
Наличие этих норм ещё не подключает динамику океана к прогнозу.

В базовом наборе нет точки росы на 2 м.
Осадки заданы за шесть часов; наш трёхчасовой интервал требует собственных норм.
Нормы временных приращений `diffs_stddev_by_level.nc` не используются как нормы состояния.
Нормы атмосферной температуры не применяются к спутниковой яркостной температуре.
Продукция и каждый физический канал требуют собственных норм обучающей части.

## Подготовить нормы без сети

Установите зависимости `data` из README.
Используйте новый путь результата: существующие нормы не перезаписываются.

```bash
python -m global_weather.import_climatology --bundled --output data/normalization/graphcast-base.json
```

Команда проверяет SHA256 встроенных NetCDF и сохраняет `NormalizationBundle`.
Файлы также включены в устанавливаемый пакет.
При повторном импорте одинаковых файлов получается одинаковый отпечаток норм.
Текущая дата запуска не меняет их идентичность.

Дополните набор по подготовленной обучающей выборке:

```bash
python -m global_weather.pipeline fit-norms --dataset data/prepared/unscaled.json --base data/normalization/graphcast-base.json --output data/prepared/normalized.json
```

Замените пример пути фактическим манифестом.
Состав частей выборки и происхождение должны пройти проверку до расчёта.
Для точки росы и трёхчасовых осадков используются только цели части `train`.
Шестичасовая дисперсия не делится на два.

Если нужны спутниковые последовательности, отдельно выполните `multimodal fit-sensors`.
Порядок описан в [многомодальной модели](MULTIMODAL.md).
Валидация и итоговый тест не участвуют в расчёте норм.

## Где используются нормы

| Компонент | Нормировка |
|---|---|
| Скалярные станции и аэрология | `NormalizationBundle` перед кодировщиком |
| Профильный и приземный декодеры | Обратное преобразование тем же набором |
| Ошибка обучения | Масштаб σ той же величины и уровня |
| ResU-Net, ConvGRU | Собственные нормы физических каналов прибора |
| Микроволновой MLP и GRU | Собственные нормы согласованных СВЧ-каналов |
| Производная продукция | Собственные нормы с методом и глубиной слоя |

Смена норм изменяет схему модели и контрольной точки.
Работа без норм разрешена только в явно синтетических проверках.
Базовая сравнительная демонстрация сохраняет инженерные масштабы; это не рабочая климатическая нормировка.

## Скачать уже собранный DEM

Артефакт находится в запуске `37203926389`:

[Скачать глобальный DEM через GitHub](https://github.com/f2re/global-ml-weather/actions/runs/37203926389/artifacts/11303707893).

Он содержит NetCDF, SHA256 и полный паспорт с хэшами 288 исходных плиток.
Срок хранения артефакта заканчивается 2 января 2027 года.
Сохраните локальную копию до этой даты.
Артефакт не является постоянным зеркалом или выпуском программной модели.

При установленном и авторизованном GitHub CLI:

```bash
gh run download 37203926389 --repo f2re/global-ml-weather --name global-dem-30s-under-900mb --dir data/dem
cd data/dem
sha256sum -c earth_relief_30s_p.nc.sha256
```

Ожидаемая SHA256 NetCDF:

```text
b221586d6cb5ca9b8d848e67771a730487178b0133a6d85449d789c7cc7f0013
```

Для самостоятельной повторной загрузки существует `scripts/download-reference-dem.py`.
Он требует `--network`, NumPy, rasterio и netCDF4.
Скрипт скачивает официальный набор и проверяет покрытие, координаты, упаковку и конечный размер.
При превышении 900000000 байт он останавливается без скрытого уменьшения разрешения.

```bash
python scripts/download-reference-dem.py --output data/dem-new --network
```

Новый выпуск источника или другие параметры сжатия могут изменить байты NetCDF.
Не отменяйте проверку старого SHA256 ради приёма нового файла.
Сохраните новый паспорт и оформите изменение ресурса отдельным экспериментом.

## Достаточен ли масштаб

Шаг 30 угловых секунд соответствует примерно 0,93 км по меридиану.
Исходный набор предварительно сглажен фильтром шириной около 2,6 км.
Это не несглаженная цифровая модель поверхности с деталями каждого километра.

Для наших глобальных ячеек порядка 56–112 км такой источник достаточен как начальный рельеф.
Детальный рельеф сам по себе не создаёт прогноз погоды с километровым разрешением.
Для узких долин, склоновых потоков и локальной орографической коррекции понадобятся отдельные методы.

## Подготовить рельеф для обучения

Сначала получите независимые статические поля высоты и доли суши на сетке модели.
Их подготовка из ERA5 описана в [обучении](TRAINING.md).
Не определяйте сушу по знаку высоты DEM: ниже уровня моря существуют участки суши.
Морская глубина не является высотой нижней границы атмосферы.

```bash
python -m global_weather.terrain --dem data/dem/earth_relief_30s_p.nc --manifest assets/dem/earth_relief_30s_p.json --reference-static data/prepared/static.npz --mesh-level 3 --confirm-landmask --output data/prepared/static-dem.npz
```

Число `3` должно совпадать с сеткой вашей выборки.
Параметр `--confirm-landmask` подтверждает, что оператор проверил независимый источник маски.
Он не создаёт эту маску и не удостоверяет её точность.

Адаптер читает ближайшие центры DEM блоками, без загрузки всего массива в память.
Масштаб 0,5 м применяется ровно один раз.
Высоты заменяются только в ячейках с независимой долей суши, равной единице.
На воде и в смешанных ячейках сохраняется исходная орография.
Отрицательные высоты подтверждённой суши не обрезаются.

Это точечная выборка, не среднее по площади гексагона.
Площади, дисперсия рельефа и консервативное укрупнение требуют отдельного оператора.
Высота в метрах не приравнивается к геопотенциалу в м²/с².
Различие геометрической и геопотенциальной высоты сохранено как допущение данного этапа.

Новый файл содержит прежние `elevation_m`, `land_fraction` и паспорт преобразования.
Укажите его как `static` в новом плане выборки и выполните `pipeline assemble`.
Рельеф поступает в начальное состояние всех трёх моделей.
Адаптивные модели также используют его в физических признаках и направленных связях графа.
Нормировка геометрии `height/5000` остаётся инженерным масштабом, а не климатической σ.

После смены рельефа создайте новый эксперимент.
Не продолжайте старый запуск с изменённым хэшем статического файла.
Маски подземных целей по-прежнему определяются целевым давлением, а не высотой, которую удобнее предсказать.
