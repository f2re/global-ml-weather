# Проверки 0.2.0 — 3 октября 2026 года

Среда: Python 3.13.5, PyTorch 2.10.0+cpu, NumPy 2.3.5,
SciPy 1.17.0, xarray 2026.4.0. CPU, один поток в тестах.

`PYTHONPATH=. python -m pytest -q`: **92 passed** (локальный запуск, 3,60 с).
Сюда входят прежние 56 тестов и 36 дополнительных случаев. Проверены
перестановка значений каналов, влияние ветра/стратификации, K=4/8/16/38,
выход 37 уровней и +72 ч, маска продукции, фоновое состояние, задержки,
повторное усвоение, фиксированные z-нормы, интервалы осадков, хэши, проверка
периода, несовместимые контрольные точки и неизменность статистических буферов.

Консервативный обмен проверен по площадному интегралу; гидростатическая ошибка —
по изотермическому профилю, маскам и подключению к обучающему шагу.

Синтетический расчёт на 42 и 162 ячейках: анализ + 24 срока до +72 ч, K=8,
D=16, все 37 выходных изобар, конечные значения. Для 162 ячеек:
23175 обучаемых параметров; форма скрытого состояния [162, 8, 16].
Два шага оптимизатора на синтетической задаче:
[3.9682548958808184e-05, 1.588359009474516e-05].
Это не свидетельство метеорологического качества или производительности рабочей сетки.

Импорт GraphCast проверен на явно синтетических NetCDF: переставленные уровни,
единицы, накопление 6 ч, переведение метров воды в kg/m², SHA256 и отсутствие
неподтверждённых переменных. **Реальные облачные NetCDF в этой среде не получены.**
Проверены исходные ссылки и схема на GitHub, но не численные коэффициенты.

`compileall` выполнен. GitHub Actions настроен на Python 3.11 и 3.13, включает
старый и новый синтетические расчёты. Его результат следует смотреть по коммиту;
данный локальный отчёт не утверждает, что удалённый запуск уже завершился.

Не испытывались реальные спутниковые файлы, метеорологическое обучение,
полный водный/энергетический баланс, HEALPix-модель и оперативный сервис.
