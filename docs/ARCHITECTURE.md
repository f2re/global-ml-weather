# Архитектура 0.2

Актуальное решение: [физически адаптивное ядро, сжатая вертикаль, память анализа
и нормы реанализа](decisions/0002-physically-adaptive.md).

```text
Разреженные наблюдения за 12 ч → QC, времена и идентичность сообщений
  → фиксированная z-нормализация → совместный код значения/канала/источника
  → представление 37 изобар + поверхность
  → сжатие в 8 скрытых позиций на ячейку
  → многомасштабный направленный граф с физическими признаками состояния
  → обновление через 3 ч, до 24 шагов
  → декодирование 37 профилей и поверхности
  → маски подземных уровней и области выдачи
```

Собственный фоновый анализ может уточняться только новыми версиями наблюдений.
Продуктовая маска не обрезает глобальную динамику. Глобальная сетка пока фиксирована.

`GlobalWeatherModel` — исправленный базовый вариант для сравнений.
`AdaptiveWeatherModel` — новая исследовательская ветвь. Конфигурация целевого
эксперимента — `configs/adaptive_v2.json`; она не запускает автоматическое обучение.
