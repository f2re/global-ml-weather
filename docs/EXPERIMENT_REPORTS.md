# Отчёт из сохранённого эксперимента

Модуль `global_weather.experiments.report` строит таблицы и графики из результатов `global_weather.pipeline`.
Он не выполняет обучение, прогноз или повторную оценку целей.
Применяйте [контракт удалённых экспериментов](../agents/REMOTE_EXPERIMENT_CONTRACT.md).
Построение выполняйте на узле `user@10.7.88.12` по зафиксированному SHA.

## Требования

Используйте отдельное окружение проекта и завершённый каталог обучения.
Каталог должен содержать `setup.json`, `history.json`, `report.json`, `best.json` и выбранные веса.
Модуль сверяет историю, тип данных, отпечатки выборки, выбор эпохи и фактический SHA256 весов.
Для показателей прогноза передайте отдельный отчёт команды `pipeline evaluate`.
Оценка должна использовать те же веса и нормы.
Её выборка может отличаться от обучающей выборки.

## Порядок

Следующая команда содержит заменяемые пути примера.
Запускайте её на удалённом узле из рабочей копии проекта.

```bash
python -m global_weather.experiments.report \
  --run outputs/example-training \
  --evaluation outputs/example-test.json \
  --output outputs/example-summary
```

1. Замените пути фактическими каталогом обучения, файлом оценки и новым каталогом отчёта.
2. Сохраните команду, рабочий каталог, UTC начала и конца, ограничения и код возврата.
3. Проверьте `summary.json` и контрольные суммы в `artifacts.json`.
4. Передайте отчёт верификатору вместе с исходными паспортами и таблицами.

Без `--evaluation` команда сохраняет только историю обучения и измеренное время эпох.
Отсутствие оценки явно отражается в `summary.json`.
Ошибочный, неполный или противоречивый вход завершает CLI с кодом `1`.
Существующий каталог результата не перезаписывается.

## Артефакты

| Файл | Содержание |
|---|---|
| `summary.json` | Тип данных, выбранная эпоха, исходные показатели, конфигурация, среда, отпечатки и ограничения |
| `epochs.csv` | История train/validation, горизонты и измеренное время эпох |
| `learning.svg` | Функции потерь по эпохам |
| `epoch_time.svg` | Измеренное время эпох в секундах |
| `scores.csv` | Фактические метрики отдельных величин, уровней и заблаговременностей при наличии оценки |
| `lead_*.svg` | MAE, RMSE и смещение по срокам отдельно для каждой величины и уровня |
| `artifacts.json` | SHA256 построенных таблиц, графиков и сводного отчёта |

Модуль не объединяет ошибки разных единиц и уровней.
Он не интерполирует отсутствующие сроки.
`count` обозначает число пригодных целей, но не долю пространственного покрытия.
Контрольный прогноз текущего конвейера сохраняет начальный анализ той же модели.
Он не является независимым численным прогнозом погоды.

## Ограничения доказательств

Синтетический эксперимент сохраняет `data_kind=synthetic` на таблицах и графиках.
`real` повторяет заявленный тип исходного эксперимента, но не удостоверяет поставщика.
Модуль всегда сохраняет `meteorologically_validated=false`.
Он не выдаёт сводку за научную приёмку.

Время эпох взято из измеренного `elapsed_seconds`.
`estimated_activation_bytes` хранится отдельно как теоретическая оценка, а не измеренная память.
Модуль не вычисляет память обучения, FLOPs и скорость прогноза из времени эпох.
Потери train и validation могут иметь разные горизонты и состав.
Их кривые не доказывают преимущество архитектуры.

Отпечатки норм и выборок берутся из результатов обучения.
Исходные массивы и файлы норм здесь не перечитываются.
Модуль сохраняет SHA256 входных JSON-файлов и проверенных весов.
Период, целевые маски, происхождение и независимость проверяйте по исходным паспортам.
Отчёт не заменяет карты покрытия, сравнение сетей и независимые метеорологические испытания.
