# Словарь проекта

## Правило

Используйте термин в указанном смысле.
Идентификаторы кода сохраняйте без перевода.
Словарь задаёт язык проекта, а не официальный словарь ASD-STE100.

| Термин | Значение |
|---|---|
| Наблюдение | Измерение с местом, временем, единицей и происхождением |
| Исходный файл | Неизменённый файл поставщика |
| Поставщик | Проект или организация, которые предоставляют исходные данные |
| Коннектор | Модуль получения или чтения данных источника |
| Адаптер | Преобразование определённого внешнего формата в контракт проекта |
| Контракт данных | Требования к структуре и смыслу полей |
| Карантин | Сохранение источника без допуска к следующему этапу |
| Физический канал | Спектральный канал прибора с подтверждённым назначением |
| Транспортный канал | Позиция в передаваемом или сохранённом потоке данных |
| Цифровой отсчёт | Число до подтверждённого физического преобразования |
| Яркостная температура | Радиометрическая температура; не температура воздуха на изобаре |
| Геометрия измерения | Координаты, угол обзора, время и область чувствительности |
| Антенное пятно | Область чувствительности микроволнового измерения |
| Время наблюдения | Момент или интервал измерения |
| Время готовности | Момент, когда завершённая обработка позволяет использовать продукт |
| Версия наблюдения | Конкретная редакция измерения с устойчивым идентификатором |
| Норма | Фиксированная статистика обучающей выборки с происхождением |
| Z-нормализация | Преобразование `(x − μ) / σ` |
| Анализ атмосферы | Восстановленное состояние к указанному сроку |
| Собственный фон | Предыдущее состояние, перенесённое ядром этой модели |
| Прогнозный выпуск | Расчёт от фиксированного начального срока |
| Заблаговременность | Интервал между начальным и прогнозным сроками |
| Цель обучения | Значение, с которым сравнивается результат модели |
| Маска | Явный признак наличия или допустимости значения |
| Скрытая позиция | Обучаемое представление колонки; не физическая изобара |
| Контрольная точка | Веса и схема состояния, сохранённые для совместимой загрузки |
| Контрольный прогноз | Метод сравнения на согласованных целях и доступности |
| Синтетический тест | Проверка на специально созданных данных, не на наблюдениях |
| Физическая диагностика | Проверка определённого свойства, не всей точности погоды |
| Верификация прогноза | Сравнение с независимыми целями |
| Инженерная приёмка | Проверка кода, интерфейса, контрактов и воспроизводимости |
| Научная приёмка | Проверка физической обоснованности и прогнозного качества |
| Артефакт | Сохранённый результат с происхождением и контрольной суммой |
| SHA256 | Контрольная сумма файла; не подпись автора |
| CI | Автоматические проверки конкретного коммита |
| Агент | Роль исполнителя с инструкциями; наличие файла не доказывает запуск |

## Не смешивать понятия

Совместимость контейнера не означает физический допуск.
Физический допуск не подтверждает точность прогноза.
Среднее по уровню не является локальной сезонной климатологией.
Маска отсутствия не является нулевым измерением.
`omega` в Па/с не является вертикальной скоростью в м/с.
Успешный CI не заменяет независимую научную приёмку.
