# Профильный опыт R7

R7 проверяет фиксированные многоуровневые нормы GraphCast по [решению 0010](decisions/0010-graphcast-fixed-normalization.md).
Этот паспорт не подтверждает уже выполненное обучение.
Координатор сохраняет испытанный SHA, команды, ограничения, журналы и фактический статус службы отдельно.

## Постановка

Входы и цели — допущенные реальные измерения IGRA.
Реконструкция S1 удерживает целые профили.
Прогноз S2 получает только доступные измерения собственной 12-часовой истории.
При обучении его выход сравнивается с отдельными будущими измерениями до 72 часов.
Прогнозный режим не читает будущие цели.
Оператор сохраняет фактические время, давление и координаты измерения.
Пропуски остаются отдельными масками.
Внутреннее состояние сохраняет глобальную сферу и 37 изобар.

Температура, влажность, ветер и геопотенциал используют фиксированные профильные μ/σ GraphCast.
Период задают фактические атрибуты NetCDF: начало 2 января 1979 года и конечный год 2015.
Это глобальные многолетние статистики по давлениям, а не месячная климатология.
Каталоги: [источники норм](../configs/normalization_sources.json) и [наблюдательные нормы](../configs/observation_normalization_catalog.json).
Для прочих каналов нормы рассчитываются только по собственным допущенным измерениям train.

R7 использует физическое линейное нормирование q и обратное восстановление с ограничением отрицательных значений нулём.
R7 начинает с новых весов.
Контрольная точка R6 с преобразованием log1p не переносится.

## Бюджет и критерий

| Параметр | Значение |
|---|---|
| Сетка и ширина | mesh 1, hidden 32 |
| Окна train / validation / диагностического test | 192 / 48 / 48 |
| Скалярные записи на окно | до 2000 |
| Предел эпох и patience | 20 и 5 |

Выбор эпохи использует только наблюдательную ошибку validation.
Фактические поля ERA5 не входят в обучение, нормы, раннюю остановку и выбор гиперпараметров.
Проверка ERA5 выполняется отдельно после фиксации весов.
Этот пилот проверяет изменение норм; его бюджет не является полным обучением глобальной модели.
Реконструкция сохраняет вес 0,25; AdamW использует шаг 0,0001, weight decay 0,01 и clip 1,0.
Устройство выбирается через auto; выделен GPU 0 и восемь потоков CPU.
Ограничения: RAM 96 ГиБ, выходной каталог 64 ГиБ и резерв свободного диска 64 ГиБ.
Предельное время — `2026-10-22T10:15:00Z`; допускаются не более трёх попыток.
Служба systemd с linger сохраняет исполнение после разрыва SSH.
R7 использует имеющиеся наблюдения и кэш проверки; новая сетевая загрузка не требуется.
R6 остановлен и отключён по поручению оператора.
Сохранена контрольная точка первой эпохи; вторая прервана без подтверждённой завершённой контрольной точки.
R5 сохраняется без изменения своих весов и исходников.

## Ограничения

Нормы не заменяют отсутствующие цели и не подтверждают обученность верхних уровней.
Доступность 185 норм для пяти величин и 37 уровней не означает наличие 185 обученных сочетаний.
Неподдержанные omega, поверхность и рельеф остаются явными ограничениями.
Изменение норм не добавляет измерений и не решает все уравнения атмосферы.
Повторно используемые test и ERA5 являются диагностикой, поскольку их результаты уже просмотрены.
Сохраняйте отдельный невидимый период для последующей научной приёмки.
