# Протокол 03. Исполнение кода и безопасность

Стенд работает локально на 127.0.0.1, одним процессом сервера и одним исполнителем.
Код запускается отдельным процессом с фиксированным списком команд, без shell=True,
eval, пользовательского Python или произвольных путей. Есть очередь, отмена,
таймаут, лимит журнала, восстановление статусов после перезапуска и блокировка
каталога от двух серверов. Это не песочница для запуска недоверенного кода.

При разработке: сначала тесты, затем короткий синтетический расчёт, затем
реальные данные после проверки готовности. Не запускать самовольное массовое
скачивание, GPU-обучение, удаление файлов, git push или изменение системных сервисов.
Для нового сетевого источника нужен отдельный коннектор, лимиты и согласие оператора.

Дочерним процессам не передаются ключи API, SSH-сокеты, настройки прокси и ключи
LLM. CDS credentials размещаются оператором вне репозитория; UI их не принимает.
Не логировать секреты, содержимое .env или .cdsapirc. Загружаемые файлы не
исполняются; NPZ читать allow_pickle=False, проверять объём распаковки.

Не включать --reload или несколько uvicorn workers на одном каталоге. Нельзя
публиковать этот локальный стенд в интернет без отдельной аутентификации, TLS,
проверки авторизации и внешней защиты. CSRF и Host-проверка не заменяют вход.
При остановке сервер завершает дочерний процесс. Прерванные задачи не повторять
автоматически: повтор требует нового номера запуска.

Агенты в .claude/agents — инструкции внешнему исполнителю Claude Code, а не
фоновые демоны. agents.py — отдельный детерминированный диспетчер разрешённых
действий. Политика в Markdown не является технической песочницей для Bash.
Не обещать автоматическую работу LLM без фактического запуска и отдельной среды.

Проверки безопасности: чужой Origin и Host, отсутствующий CSRF, обход каталогов,
символические ссылки, повторная загрузка, неизвестная роль/команда, отмена,
сбой дочернего процесса и перезапуск. Никаких внешних CDN, тайлов и шрифтов.
