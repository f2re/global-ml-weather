# Обязательные протоколы

Перед работой прочитайте контракт `GLOBAL-WEATHER-OPS-1` в `agents/OPERATING_CONTRACT.md`.
Поручение оператора ограничивает допустимые действия.

| Протокол | Назначение |
|---|---|
| [01. Научная постановка](01-scientific-method.md) | Гипотезы, физика и аналитические проверки |
| [02. Данные и нормы](02-data-and-normalization.md) | Происхождение, время, маски и статистики |
| [03. Исполнение](03-execution-security.md) | Разрешённые действия, ограничения и безопасность |
| [04. Верификация и выпуск](04-verification-release.md) | Независимые цели, артефакты и приёмка |
| [05. Совместимость](05-ecosystem-compatibility.md) | Контракты Арктики, Электро-Л и SatDump |
| [06. Документация](06-russian-documentation.md) | Русский технический профиль и проверка текста |

Результат любого этапа должен иметь проверяемый артефакт.
При отсутствии доказательств запишите ограничение или блокировку.
Не заменяйте выполненную проверку описанием намерения.
Шаблон комплекта отчётов: `release-evidence.template.json`.
