# Профильный опыт R5

Применяйте [решение 0008](decisions/0008-profile-extension-and-verification-recovery.md).
Паспорт конфигурации: `configs/profile_r5_training.json`.

## Назначение и исполнение

R5 продолжает исследование на подготовленных данных R4, сохраняя прежние наблюдательные нормы.
Исходный каталог данных: `/home/user/global-ml-weather-r4-v6/outputs/remote-r4-stations/dataset`.
Родительские веса находятся в соседнем `training`; исходная ревизия — `8939d0280ef85cdd2daa5f56cb82d795e6bd1837`.
Исходные файлы и завершённые эпохи R4 не изменяются.

Служба `global-weather-r5.service` использует отдельную рабочую копию `/home/user/global-ml-weather-r5`.
Выполняются полный pytest, контрактные проверки, прежние модельные сценарии, документация и оба браузерных сценария.
После проверок следуют восстановление внешнего сравнения R4 и новое профильное обучение.
Затем запускаются отдельный наблюдательный test и внешняя диагностика R5.

Веса, оптимизатор и RNG переносятся явно через `--continue-from` и полный `--parent-commit`.
Продолжение прерванного R5 использует собственную последнюю эпоху с прежними строгими проверками.
Ошибки, неоднозначные эпохи и изменение численной среды блокируют продолжение.

## Бюджет

Новая массовая загрузка не требуется; внешняя проверка читает уже полученный кэш ERA5.
Кэш R4 ограничен прежним паспортом и используется с проверкой хэшей.
Каталог R5 ограничен 128 ГиБ; свободный резерв составляет 64 ГиБ, RAM — 96 ГиБ.
Процесс использует восемь потоков и CUDA при её доступности; численная среда переноса должна совпадать с родителем.
Служба имеет не более трёх попыток и абсолютный срок `2026-10-22T10:15:00Z`.
`Linger=yes` сохраняет работу после завершения SSH.

## Проверка результата

Успех запуска требует новой завершённой эпохи и согласованных ссылок контрольных точек.
Улучшение качества оценивается по наблюдательной validation, а не ERA5.
Повтор прежнего test обозначается диагностическим и не даёт новой независимой приёмки.
Сравнение ERA5 не изменяет веса, нормы, выбор эпохи и гиперпараметры.
Полная научная приёмка, циклический S3/C2 и обучение omega остаются незавершёнными.
