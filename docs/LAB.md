# Стенд испытаний

## Назначение

Стенд проверяет исполнение модели и показывает результаты.
Он не выдаёт необученную сеть за оперативный прогноз.
Без независимых целей точность погоды не рассчитывается.

## Требования

Используйте Linux и отдельный Python 3.10+ с CPU-сборкой PyTorch.
Не заменяйте системный Python Astra.
Docker и Node.js для работы не требуются.

**Не открывайте стенд в интернет.**
Привязка к `127.0.0.1` обязательна.
Для удалённого доступа используйте собственный аутентифицированный SSH-туннель.

## Запустить

1. Установите зависимости в разрешённое окружение.

```bash
python -m pip install -e '.[test,data,lab,ecosystem]'
```

2. Запустите один сервер для выбранного рабочего каталога.

```bash
python -m global_weather.lab.app --workspace outputs/lab --port 8765
```

3. Откройте `http://127.0.0.1:8765`.

Ожидаемый результат: страница испытаний с историей запусков.
Страница использует локальные скрипты, системные шрифты и графику.
Карты и облачные языковые модели не загружаются.

## Провести испытание

Выберите исходный или адаптивный граф.
Задайте `D`, `K`, зерно генератора и горизонт до 72 часов.
Доступны тестовые сетки из 12–642 ячеек.
Эти размеры не являются рабочим пространственным разрешением прогноза.

При необходимости исключите станции или радиозонды из синтетического входа.
Запустите задачу. Проверьте её состояние и журнал.
Синтетические шаги оптимизатора проверяют градиенты. Они не обучают модель метеорологии.

Очередь содержит до шести ожидающих задач.
Одновременно выполняется одна задача.
Отмена, таймаут и исключение не являются успешным завершением.

## Просмотреть результат

Выберите срок, величину, изобару и ячейку.
Сфера показывает действительную геометрию ячеек в ортографической проекции.
Профиль показывает значения выбранной колонки.
Серый цвет обозначает маску, а не нулевое измерение.

Проверьте гидростатический остаток и нарушения физических границ.
Эти диагностики не являются точностью погоды.
Для проверки времени используйте метки UTC и заблаговременность.

## Принять локальный файл

Загрузите отдельный файл объёмом до 32 МиБ во входной каталог.
Допустимые имена содержат латинские буквы, цифры, точку, дефис и подчёркивание.
Каталоги через HTTP не принимаются. Существующие файлы не перезаписываются.

Инспекция проверяет структуру. Она не исполняет файл и не следует вложенным путям или URL.
Для полного набора SatDump и численных растров используйте отдельные команды [совместимости](ECOSYSTEM.md).
Отсутствие геометрии блокирует экспорт в модель, но не удаляет пригодный промежуточный растр.

## Сравнить с независимыми целями

Подготовьте явно сопоставленные массивы и манифест.
Команда сравнения работает отдельно от просмотра синтетических полей.

NPZ содержит `prediction`, `target`, булеву `mask`, `lead_hours`, `area_m2` и необязательный `baseline`.
Форма данных: `[срок, ячейка]` либо `[срок, ячейка, уровень]`.
Манифест содержит `variable`, `units`, `target_source`, `forecast_source`, `data_kind` и `paired_sha256`.

```bash
python -m global_weather.lab.evaluate --pairs pairs.npz \
  --manifest pairs.manifest.json --output evaluation.json
```

Результат содержит MAE, RMSE и смещение.
При наличии контрольного прогноза рассчитывается относительное улучшение RMSE на тех же целях.
Отсутствующая цель не означает ошибку 0.
Расчёт метрик не удостоверяет независимость периода.

## Хранение и перезапуск

`experiments.sqlite` хранит состояния и параметры задач.
`inbox/` содержит файлы оператора.
`runs/<id>/` содержит запрос, журнал, отчёты, геометрию и массивы сроков.

Отчёты фиксируют UTC, зерно, версии, хэши кода и результатов.
Вне Git поле коммита может быть `null`. Хэши файлов при этом сохраняются.

После перезапуска незавершённые задачи получают `interrupted`.
Повтор требует нового запуска.
Два сервера не могут использовать один рабочий каталог.
`flock` и ограничения ресурсов рассчитаны на Linux; переносимость на Windows не заявляется.

## Не реализовано

Нет обученных весов и полного набора реальных норм.
Не завершены спутниковые декодеры, антенный оператор и полный водно-энергетический бюджет.
Промышленная авторизация и научная приёмка отсутствуют.
При изменении интерфейса выполните `python scripts/browser-test.py` в подготовленном Playwright.
