## Локальная проверка

Команда:

```bash
PYTHONPATH=. python -m pytest tests/test_ecosystem.py tests/test_agent_contracts.py -q
python -m compileall -q global_weather
```

Получено: **48 passed**, без пропусков в указанном наборе, rasterio установлен.
Синтетические GeoTIFF и CBOR созданы для проверки контрактов, а не выданы за
наблюдения. Проверены канал/калибровка, два формата МТВЗА, пропуски и отказы,
сохранение пригодных частей набора, запрет повторной шкалы values.tif, маски QC,
координаты, время доступности, хэши, отсутствие геометрии, экспорт в контракт
pack_observations, правила всех девяти ролей и блокирующая проверка отчётов.

Ограничение локального окружения: использована доступная исходная копия проекта
0.1 для неизменившихся базовых API и новый набор файлов. Полного checkout 0.3
в контейнере нет; текущие файлы 0.3 и tests/test_lab.py прочитаны через GitHub.
Этот результат **не является прогоном всей текущей main**, старых тестов
адаптивного ядра, FastAPI-сервера или браузера. Обязателен полный прогон после
наложения на указанную main. Конфигурация CI дополнена, но новый CI не запускался.

## Не выполнено

Публикация изменений, сквозной запуск фактического SatDump, проверка реальных
спутниковых проходов, радиометрическая калибровка МТВЗА, антенный оператор,
научная оценка прогноза, независимая рецензия другим агентом и полный браузерный
прогон новой ревизии. Ни один из этих пунктов не следует из числа passed.

Собственные каталоги приёма, .ready, .download.json, конфигурации и службы
пользователя не изменялись. Промежуточный физический растр и согласованный
транспорт не означают автоматического допуска источника в обученную модель.

Скрипт наложения комплекта отдельно проверен семью синтетическими тестами: без
записи по умолчанию; запись/резервная копия без commit; отказ при подмене
контрольной суммы, изменённой рабочей копии, другой ветке/HEAD и конфликте с
игнорируемым пользовательским файлом. Он не выполняет сетевых операций.
