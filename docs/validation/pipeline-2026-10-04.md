# Проверка программного цикла 0.4

Дата: 4 октября 2026 года.
Базовая ревизия перед изменениями: `cd11ebf58804eb9bac2092b749d4e42838515645`.

## Изменения

Добавлены подготовленная выборка, потоковый расчёт норм, адаптер целей ERA5 и CPU-цикл обучения.
Добавлены продолжение по завершённой эпохе, отдельная оценка и прогноз по сохранённым весам.
Страница обучения использует прежнюю очередь и фиксированный диспетчер задач.
На основной карте можно открыть результат обученного исследовательского прогноза.

## Локальные результаты

47 проверок нового модуля прошли без пропусков.
Проверено точное совпадение весов после непрерывного и возобновлённого обучения.
Проверен прогноз при запрещённом загрузчике будущих целей и отдельном манифесте без целей.
Проверены временные разбиения, нормы обучающей части, повреждённые файлы и небезопасные заголовки массивов.
Ветер проверен как вектор с меняющимся локальным базисом, а не как два независимых скаляра.
Отозванная новая версия наблюдения не восстанавливает старое значение.

Сквозной аналитический пример прошёл обучение, проверку и прогноз до +72 часов.
Получены 25 сроков и 5520 строк метрик по независимой от обучения синтетической части.
Эти числа подтверждают исполнение, а не точность погоды.

Локальная рабочая копия собрана из доступных архивов и прочитанных исходников.
Ключевые файлы ядра сверены по Git blob SHA с базовой ревизией.
Полная проверка канонического дерева выполняется GitHub Actions на публикуемом коммите.
Результат удалённого запуска следует смотреть по итоговому SHA; данный файл не предрешает успех CI.

## Область проверок CI

Существующие задания проверяют весь набор тестов на Python 3.11 и 3.13.
Они также проверяют прежний браузерный сценарий, документацию и закреплённые исходники поставщиков.
Новое задание `prepared-data-pipeline` выполняет сквозной расчёт до 72 часов и новый браузерный сценарий.
Браузер проверяет выборку, обучение, итоговый тест, прогноз, профили и мобильную ширину.

## Что не проверено

Многосезонное обучение на реальном архиве и научная точность прогноза не проверены.
Реальные приёмники, установленный SatDump и калибровка МТВЗА не испытывались.
Численные базовые статистики GraphCast не скачаны в рамках этой проверки.
Реальные GeoTIFF и CF-NetCDF требуют отдельных проверок источника; тестовые файлы созданы аналитически.
Площадное сохранение не заявляется для билинейного переноса в центры ячеек.
Промышленное масштабирование, динамическая поверхность и полный водно-энергетический бюджет остаются отдельными этапами.
