# Проверка сборки геофизического контекста

Исходная ревизия: `0b65cbfbd2ba7026a5d2679addd222155c997f41`.
Изменения: новый оптический оператор, сохранение метода в реестре и пакетная сборка продукции.
Новый код не заменяет существующие спутниковые адаптеры или многомодальное ядро.

Локально выполнены 22 аналитических теста оптической инверсии.
Использован точный снимок исходного `products/core.py`; его Git blob совпадает с исходной ревизией.
Новые файлы прошли compileall.
Полной исходной копии проекта в этой локальной среде нет.
Поэтому локальный результат не объявляется результатом полного набора тестов.

Полная проверка должна выполняться в GitHub Actions для итогового коммита.
Она включает новые пакетные тесты, существующие проверки продуктов, обучение и расчёт до 72 часов.
В отдельном случае NDVI, влажность почвы, высота облаков и LWP проходят совместную сборку и приём кодировщиком.
Другой случай проверяет ненулевой градиент от нового облачного продукта и полный горизонт.

Таблица облачной инверсии в тестах аналитическая и явно синтетическая.
Испытания подтверждают математику, причинность, маски, отказы и программное подключение.
Они не подтверждают радиометрическую точность или улучшение прогноза реальной погоды.
Таблицы переноса излучения для российских приборов, реальные проходы и независимая метеорологическая проверка остаются обязательными.
