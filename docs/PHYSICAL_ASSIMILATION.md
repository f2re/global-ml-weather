# R11: физически согласованная ассимиляция и прогноз

Контур `physical-assimilation-r11` усваивает измерения всех платформ и прогнозирует до 72 часов.
Постановка закреплена [решением 0020](decisions/0020-physical-assimilation-r11.md).
Реальное обучение ещё не выполнялось; научная приёмка отсутствует.

## Схема

```text
измерения в своих координатах и времени (станции, суда, зонды, самолёты, AMV, RO, спутники)
  → допуск, причинный отбор available_at <= issue, нормы train, ошибки наблюдений
  → энкодер: 7 ближайших узлов, гауссово ядро, 8 слоёв ln p + поверхность + лимб + столб
  → анализ: 8 слоёв multimesh уровней 0–5 на mesh 5
  → физическое состояние: ln p_s, T, RH, ветер ×37, приземные T, RH, ветер
  → шаг 3 ч: 8 слоёв multimesh, приращение, ограничения
  → Φ от Φ_s = g·z_s, сохранение сухой массы, omega с условием dp_s/dt
  → оператор наблюдений → потери Huber или CRPS в пространстве измерений
```

## Физические ограничения

| Соотношение | Реализация | Код |
|---|---|---|
| Гидростатика | Φ интегрируется по ln p вверх от поверхности; трапеция по Tv | `thermo.geopotential_from_surface` |
| Нижняя граница | Φ(p_s) = g·z_s точно; z_s — среднее DEM по площади ячейки | `thermo`, `static.py` |
| Масса сухого воздуха | Равномерный сдвиг p_s после каждого шага, метод Ньютона | `thermo.correct_dry_air_mass` |
| Насыщение | q = RH·q_s(T, p), RH ≤ 1,05 относительно воды; лёд допускает пересыщение | `thermo.specific_humidity_from_logit` |
| Ветер | Декартов вектор в глобальной системе, проекция на касательную плоскость | `model.decode` |
| Omega | Неразрывность, ω(1 гПа) = 0, ω(p_s) = ∂p_s/∂t + V_s·∇p_s по О'Брайену | `thermo.omega_with_lower_boundary` |
| MSLP | Условная редукция с градиентом 6,5 К/км под поверхностью | `thermo.mean_sea_level_pressure` |
| Давление станции | Гипсометрия от модельной поверхности до высоты станции | `thermo.pressure_at_height` |
| Температура станции | Собственный градиент модели между поверхностью и станцией | `operator.observe` |
| Инсоляция | Солнечная постоянная, склонение и уравнение времени по Спенсеру | `thermo.toa_insolation` |

Замкнуты только перечисленные соотношения.
Баланс влаги и энергии, осадки, облачность и пограничный слой не моделируются явно.

## Наблюдения

| Платформа | Величины | Вертикальная координата | Источник |
|---|---|---|---|
| Наземные станции | T, Td, ветер, давление станции, MSLP | высота станции из GHCNh | `GhcnhSource` |
| Суда, буи | те же | явная высота платформы | хранилище |
| Скаттерометр | приземный ветер | поверхность | хранилище |
| Зонды, дропзонды | T, q, u, v, Φ | фактическое давление уровня | `IgraSource`, хранилище |
| Шары-пилоты, профилометры, AMV | u, v | давление | хранилище |
| Самолёты | T, q, u, v | давление на эшелоне | хранилище |
| GNSS-RO | рефракция N | высота касания | хранилище |
| Спутниковые каналы и продукты | Tb или продукт | столб, зенитный угол | хранилище с паспортом |

Межсрочные и нерегулярные измерения поступают со своим временем без округления.
Движущиеся платформы передают координаты каждого измерения.
Позднее сообщение входит в анализ только после своего `available_at`.
Одна версия измерения в окне запрещена; повтор отклоняется.

Нормы входа для T, q, u, v и Φ — закреплённые μ/σ GraphCast в фактическом давлении.
Нормы остальных величин считаются только по train своего источника.
Давление станции нормируется после редукции ln p + z / 8000 м.
Ошибки наблюдений заданы в `configs/observation_errors_r11.json`.
Спутниковые ошибки берутся из радиометрического паспорта.

## Обучение

S1: целиком удержанные станции, запуски и рейсы восстанавливаются анализом в окне ±1,5 ч.
S2: будущие измерения сравниваются с прогнозом через оператор наблюдений.
S3: фоном служит собственный прогноз прошлого цикла на +6 ч.
В циклированный анализ входят только сообщения, ставшие доступными после прошлого выпуска.
Цели вне 1–1000 гПа и станции без высоты для T, Td и давления отклоняются с причиной.
Цель никогда не скрывается предсказанным давлением у поверхности.

| Этап | Развёртка | Эпохи × выпуски | Шаг обучения | Члены | Циклирование |
|---|---|---|---|---|---|
| S1+S2 | 6 ч | 40 × 1024 | 3e-4 → 3e-6, прогрев 500 | 1 | нет |
| S2 | 24 ч | 15 × 512 | 3e-5 → 3e-6 | 1 | нет |
| S2+S3 | 72 ч | 10 × 256 | 1e-5 → 1e-6 | 1 | да |
| S2-E+S3 | 72 ч | 6 × 256 | 5e-6 → 5e-7 | 2, честный CRPS | да |

## Гиперпараметры

| Параметр | Значение | Обоснование |
|---|---|---|
| `mesh_level` | 5: 10242 узла, шаг 241 км | Около 2·10³ пунктов; выход mesh8 возможен отдельным декодером |
| `multimesh` | уровни 0–5, 81900 рёбер | Глобальная связь за несколько слоёв, как в GraphCast |
| `processor_layers` | 8 | Минимальная дальность за шаг 17843 км ≥ 1620 км |
| `analysis_layers` | 8 | Распространение измерений на весь шар до физического состояния |
| `hidden` / `message_dim` | 256 / 64 | 8,24 млн параметров против 29547 в пилоте R9 |
| `encoder_neighbours` | 7 | Узел и кольцо соседей; ширина ядра обучается |
| `issue_stride_hours` | 6 | Все синоптические сроки, около 1432 окон train |
| `input_dropout` / `holdout_fraction` | 0,2 / 0,15 | Устойчивость к пропускам и обучение пространственному переносу |
| `analysis_weight` | 0,5 | Анализ важен, но прогноз остаётся главной целью |
| `huber_delta` | 3 | Ограничение влияния грубых ошибок, аналог VarQC |
| `optimizer` | AdamW, β = (0,9; 0,95), wd 0,1, клип 1 | Без затухания весов для смещений, норм и эмбеддингов |
| `precision` | bf16 на CUDA, состояние float32 | 1 К при 300 К требует около 12 бит мантиссы |
| `checkpoint_steps` | true | Повторный расчёт шагов и слоёв вместо хранения активаций |

Один пример mesh5 на 6 ч занял 5,7 ГБ RSS на CPU; память CUDA ещё не измерена.

## Запуск на вычислительном узле

Замените пути фактическими каталогами допущенных архивов.

1. Подготовьте статику mesh 5 по площади ячейки:

   ```bash
   python -m global_weather.assimilation prepare-static --dem data/dem/earth_relief_30s_p.nc --dem-manifest assets/dem/earth_relief_30s_p.json --land-geojson data/land.geojson --land-sha256 <sha256> --mesh-level 5 --output data/r11/static-mesh5
   ```

2. При необходимости допустите дополнительную платформу:

   ```bash
   python -m global_weather.assimilation prepare-store --input data/aircraft.jsonl --platform aircraft --output data/r11/stores/aircraft
   ```

3. Выполните самопроверку программы:

   ```bash
   python -m global_weather.assimilation selftest --output outputs/r11-selftest
   ```

4. Выполните короткий прогон на реальных данных:

   ```bash
   python -m global_weather.assimilation train --config configs/physical_assimilation_smoke.json --surface <GHCNh> --profile <IGRA> --static data/r11/static-mesh5 --output outputs/r11-smoke
   ```

5. Запустите основной опыт:

   ```bash
   python -m global_weather.assimilation train --config configs/physical_assimilation_r11.json --surface <GHCNh> --profile <IGRA> --static data/r11/static-mesh5 --output outputs/r11
   ```

6. Оцените зафиксированные веса на validation, затем один раз на test:

   ```bash
   python -m global_weather.assimilation frozen score --training outputs/r11 --split validation --surface <GHCNh> --profile <IGRA> --static data/r11/static-mesh5 --output outputs/r11/validation.json
   ```

7. Сформируйте ансамблевый прогноз:

   ```bash
   python -m global_weather.assimilation frozen forecast --training outputs/r11 --issue 2022-09-01T00:00:00Z --members 8 --surface <GHCNh> --profile <IGRA> --static data/r11/static-mesh5 --output outputs/r11/forecasts
   ```

Продолжение после прерывания требует полного совпадения конфигурации, данных, норм, ошибок, статики и исходников.

## Критерии приёмки

| Ворота | Проверка | Порог |
|---|---|---|
| 0 | Самопроверка | все восемь свойств выполнены |
| 1 | Область зависимости за шаг | не меньше 1620 км |
| 2 | Анализ удержанных станций и запусков | RMSE ниже инерции и климата |
| 3 | Масса сухого воздуха за 72 ч | дрейф не больше 10⁻⁶ |
| 4 | Прогноз +24/+48/+72 ч на закрытом периоде | лучше инерции и климата с 95 % интервалом по эпизодам |
| 5 | Баланс и спектры | доля дивергентной энергии не падает быстрее эталона |

Пороги ворот 2–5 нужно закрепить до запуска опыта.
ERA5 допускается только для отдельной проверки зафиксированной модели.

## Ограничения и следующие шаги

Ошибки наблюдений требуют калибровки по диагностикам Desroziers на сохранённых отклонениях.
Снос зонда не восстанавливается.
Выход на mesh8 и GRIB2 требует отдельного декодера и проверки.
Спутниковые цели требуют физического допуска каналов.
