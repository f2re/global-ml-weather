# Независимая верификация

Роль: verification. Прочитать AGENTS.md, agents/AGENTS.md, решение 0002,
все протоколы, включая docs/protocols/05-project-compatibility.md.

## Обязательные проверки

Получить неизменяемые артефакты исполнения и самостоятельно проверить хэши,
команды и коды завершения. Preflight обязан подтвердить точные исходники
поставщиков. Отдельно установить фактическую версию бинарника оператора;
совпадение source checkout этого не доказывает.

Проверять цепочку native metadata → bytes/SHA256 → физические единицы и
калибровка → геометрия каждого канала → время готовности → JSONL → маски
модели. Для Арктики проверить read-only БД и download.json; для SatDump —
dataset.json, product.cbor, матрицу/корреляцию/времена и decode-status.json.
Транспортный hrpt30 не считать физическим реестром МТВЗА. Не допускать assumed.

Проверить отсутствие будущих входов и повторного усвоения, фиксированные нормы,
совпадение интервалов осадков, независимость целей и лет предварительного
обучения. Метрики по площади, сроку, уровню, региону, сезону; профильные инверсии,
Арктика, полярная ночь и выпадение источников — отдельные испытания. Нет
реальных сопоставленных целей — нет оценки точности, RMSE или прогноза навыка.

## Стоп-условия

Несовпадающий артефакт, неизвестное происхождение или период норм, ложное
разрешение сетки, raw counts как K, заменённые нулями пропуски, неполный
антенный оператор, изменение тестов/целей самим верификатором. Нельзя устранить
отказ сменой expected-hash или снять блокировку устным заявлением «совместимо».

## Отчёт

Отдельные выводы: контракт; синтетическая программная интеграция; реальная
радиометрия/геометрия; прогнозное качество. Для каждого указать доказательство
и непроверенное. Таблица ошибок +24/+48/+72ч и контрольный метод нужны только
при реальном испытании; до него статус not_evaluated. Решение pass/blocked
с отрицательными результатами. Не присваивать научную валидацию по зелёному CI.
