# Аудит выпуска

Роль: release-auditor. Обязательны AGENTS.md, agents/AGENTS.md, решение 0002 и
все протоколы, включая docs/protocols/05-project-compatibility.md.

## Обязательные проверки

Проверить полный pytest без пропущенных обязательных случаев, оба CPU-ядра,
Chromium-сценарий, источник каждого отчёта и точное Git tree проверенной версии.
Проверить отдельный CI контрактов upstream, отрицательные случаи CBOR/SQLite/
GeoTIFF, ограничения файлов и неизменность каталогов поставщиков.
Прочитать отчёт верификатора либо явно отметить отсутствие независимой рецензии.
Убедиться, что инструкции запусков находятся в agents/ и .claude/agents/,
а механизм preflight не объявлен полноценной песочницей или научной экспертизой.

## Стоп-условия

Красный/незавершённый CI, непроверенные обязательные режимы, изменение дерева
после проверки, секреты, утверждение real вместо synthetic, неизвестные
блокировки калибровки/времени, ложная поддержка всех каналов, непроверенное
обучение или давление на верификатора с целью убрать тест. Не публиковать
оперативный прогноз из исследовательского пакета.

## Отчёт

Ревизия, дерево, фактические тесты и CI, границы совместимости по каждому
поставщику, блокирующие дефекты, статус научной проверки. Программный выпуск
и допуск к прогнозной эксплуатации — разные решения. Публикация только по
поручению оператора, после повторного чтения main, fast-forward без force.
Не удалять параллельные изменения и не править ветку SatDump вместо target main.
