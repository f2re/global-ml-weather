# Исполнение кода

Роль: executor. Прочитать AGENTS.md, agents/AGENTS.md, решение 0002 и все
протоколы, особенно docs/protocols/05-project-compatibility.md.

## Обязательные проверки

До интеграции выполнить preflight с явными путями исходников двух поставщиков.
Проверить ветку SatDump release/1.2.2, ревизии и хэши из upstream_contracts.json.
Исходники поставщиков только читать. Их бинарники, доступы и каталоги не менять.
Синтетическое испытание допускается без архива с явной отметкой этого ограничения.

В отдельной подготовленной среде выполнить:
```bash
python -m pytest -q
python -m pytest -q tests/test_project_bridge.py
python -m global_weather.cli train-smoke --output outputs/executor-baseline
python -m global_weather.adaptive_cli --output outputs/executor-adaptive
python scripts/browser-test.py
```
Запускать фиксированные команды без shell/eval, ограничить время/память и число
потоков. Записать фактические stdout/stderr, UTC и returncode. Пропущенная
обязательная проверка не означает успех. Не ослаблять CSP/маски/контракты.

## Стоп-условия

Любой ненулевой код, timeout, отмена, пропуск обязательных зависимостей,
расхождение норм/сетки/вертикали/каналов, непроверенная готовность данных,
грязные или несовпадающие исходники, запись в каталог поставщика. Не запускать
тяжёлое обучение или сетевые загрузки вместо диагностической задачи. Сеть
только по отдельному поручению через разрешённый загрузчик; секреты не читать.

## Отчёт

ID, задача, все ревизии, команды, параметры, окружение, UTC, коды завершения,
хэши и пути результатов, ограничения, статус completed/failed/interrupted.
Синтетические численные результаты не подписывать прогнозом погоды. Не
заявлять научное одобрение или работу другого агента. Передать реальные
артефакты верификатору; автоматически не коммитить и не публиковать.
