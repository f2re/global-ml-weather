# Роли разработки

## Назначение

Девять ролей разделяют разработку и проверку модели.
Все роли читают [обязательный контракт](OPERATING_CONTRACT.md) `GLOBAL-WEATHER-OPS-1`.
Для документации действует `RU-TECH-1`.

| Роль | Ответственность |
|---|---|
| `coordinator` | Гипотезы, зависимости и порядок работ |
| `data-steward` | Получение, лицензии, версии и происхождение |
| `radiometry` | Физические каналы, калибровка и геометрия |
| `normalization` | Фиксированные нормы и их период |
| `physics` | Формулы, допущения и аналитические проверки |
| `model-engineer` | Кодировщики, динамика и сравнение архитектур |
| `executor` | Разрешённые запуски и журналы |
| `verification` | Независимые цели и проверка выводов |
| `release-auditor` | Приёмка инженерной публикации |

## Запуск действий

```bash
python -m global_weather.lab.agents
python -m global_weather.lab.agents --role executor --action adaptive --execute --workspace outputs/agent-tests
```

Без `--execute` диспетчер выводит план.
Получение данных дополнительно требует разрешённого сетевого доступа и `--network`.
Разрешения роли проверяются по реестру `global_weather/lab/agents.py`.
Они не заменяют изоляцию уровня ОС.

Файлы `.claude/agents/` задают роли внешнему исполнителю Claude Code.
Они не запускают фоновые процессы сами.
Не утверждайте работу другого агента без фактического вызова и отчёта.

## Результат

Агент сохраняет задачу, гипотезу, команды, хэши, результаты и ограничения.
Отрицательные результаты включаются в отчёт.
Рецензент проверяет артефакты, а не только текст исполнителя.
Структура отчёта: [контракт](OPERATING_CONTRACT.md).

## Удалённые эксперименты и субагенты

Все девять ролей применяют [GLOBAL-WEATHER-REMOTE-1](REMOTE_EXPERIMENT_CONTRACT.md).
Контракт закрепляет машины, владение файлами, зависимости субагентов, адаптеры Арктики и «Электро-Л».
Он задаёт обучение, сравнительные расчёты, показатели, графики и возврат доказательств.
Разработка выполняется локально; загрузка, обработка данных и расчёты выполняются на user@10.7.88.12.
