# C3: координатные наблюдения и этапы обучения

## Реализованная область

Добавлен контракт `GLOBAL-WEATHER-OBSERVATIONS-1`.
ERA5 остаётся плотным учителем для проверки нейросетевого ядра.
Рабочие этапы используют фактические наблюдения и предыдущий прогноз.

Индекс станции необязателен.
Профиль определяется номером сообщения либо координатами и временем запуска.
Каждый уровень может иметь собственные координаты, время и давление.
Неполный профиль не заполняется стандартной атмосферой или ERA5.

Добавлены:

- координатная идентичность наблюдения;
- нормализация неполного движущегося профиля;
- оператор сравнения прогноза с наблюдением;
- этапы S0–S4;
- групповое исключение целых профилей;
- проверки произвольных сроков и координат.

## Граница поставки

Это частичная реализация C3.
Сетевые загрузчики IGRA и оперативного BUFR ещё отсутствуют.
TEMP и BUFR ещё не декодируются этим модулем.
Морские наблюдения и карта обеспеченности ещё не подключены.

Оператор наблюдений не является объективным анализом приращений.
Фон от предыдущего прогноза и обучение S2–S3 через C2 относятся к следующей работе.
Нельзя отмечать A02, A09, A10 и A11 выполненными по модульным тестам.

## Следующие действия

1. Добавить `providers/igra.py` и проверку настоящих профилей.
2. Добавить декодеры TEMP и BUFR с фактическими временами уровней.
3. Ввести вертикальный и гидростатический контроль качества.
4. Подключить будущие наблюдения к C2 через оператор наблюдений.
5. Реализовать фон и анализ приращений.
6. Провести эксперименты с исключением целых профилей и районов.
7. Сравнить наблюдательные метрики с ERA5 как вторичным эталоном.

## Приёмка этой области

```bash
python -m pytest -q tests/test_observation_driven.py
python -m global_weather.pipeline training-stages
python scripts/check_docs.py --strict
```

Проверки контракта не подтверждают качество анализа атмосферы.
Нужны реальные аэрологические архивы и независимые наблюдения.
